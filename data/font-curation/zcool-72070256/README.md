# 黑符椒二次元标题字体设计收录

来源：https://www.zcool.com.cn/work/ZNzIwNzAyNTY=.html

沿用用户现有 Chrome 中已打开的作品页面读取正文 19 张图，按独立设计裁出 28 张卡片。优先选用单独展示大图，汇总图与同款黑白版本不重复建卡。两款抽象设计使用描述性名称，并在卡片名称、备注中标记原中文待核。

新增 28 张；导入前有效卡片 41 张，导入后 69 张。保留用户原有卡片及其删除状态。分类：复古装饰 10、立体字效 8、细线优雅 5、几何构成 2、圆体趣味 2、语义图形 1。

每卡包含单款裁图、字形分析、配色字效、适用场景、作者与原作链接、原图地址与尺寸、裁切坐标，以及明确标记为整理所得的风格复用建议。收录为参考图片，不是可安装字体。

通过现有字体库存储接口写入，复用图片存储、缩略图、锁及原子更新；未调用付费自动整理。manifest.json 中 file 指向实际字体库持久文件；import-report.json 包含卡片 ID。已核验全部 28 张图片和备注持久存在，并在本机实际桌面窗口检查卡片与详情显示。字体库搜索“黑符椒”可查看本批。无需修改应用代码、构建或重启。
