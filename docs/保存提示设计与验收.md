# 保存提示设计与验收

参考 [Atlassian Flag usage](https://atlassian.design/components/flag/usage) 的简短标题、辅助信息、少量动作与可关闭反馈，结合项目现有 Motif 中性表面。不是复刻第三方组件。

保存成功显示低干扰的双行浮层：绿色勾选、「图片已保存」、文件名；完整路径放在辅助行的原生悬停提示中。「打开文件夹」通过桌面 IPC 定位本次成功导出的文件。主进程只接受当前会话登记的已导出路径，路径失效显示原因。

浅深主题使用现有语义 token，14px 圆角、细边框、克制阴影。180ms 进入动效，只改变透明度与位移，尊重减少动态效果设置。浮层外围不截获画布操作。

成功后 6 秒自动收起；鼠标悬停、键盘焦点或打开操作期间暂停。失败与部分失败持续显示，提供重试；重试部分失败只提交失败文件。关闭提示不取消后台下载。下载仍沿用独立桌面导出通道。

验收通过：项目/Electron 类型检查、变更文件 Lint、生产构建、原图导出回归。实际 `/Applications/环中AIStudio.app` 已更新并验证深浅主题截图、文件落盘、完整路径悬停信息、手动关闭、悬停超过 6 秒保留、键盘焦点保留、空闲自动收起。打开文件夹操作通过真实按钮与 IPC 验证传入已导出文件路径；验收暂时拦截系统 shell 调用，未弹出 Finder 窗口。未发起付费生成。真实项目、作品、输入草稿与设置保留，不将用户工作期间新增的内容回滚。
