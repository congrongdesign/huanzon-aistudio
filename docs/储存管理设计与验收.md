# 储存管理

## 参考与取舍

已阅读官方说明：

- [Adobe Lightroom 偏好设置](https://helpx.adobe.com/lightroom-cc/using/preferences.html)：区分原文件、智能预览、照片缓存和可用空间；可设置缓存上限与原文件位置。
- [macOS 储存设置](https://support.apple.com/guide/mac-help/free-up-storage-space-mchl3d437fbc/mac)：展示分类占用，进入分类查看文件，再选择删除。

据此采用“空间概览 → 图片位置 → 缓存策略 → 扫描明细 → 确认清理”。沿用现有 Motif 中性色和 Radix 弹窗。危险项目不默认选中，缓存默认选中。全部数字来自实际文件统计。

## 已实现

设置新增独立“储存管理”，与“下载与资产”分开。图片库位置影响生成、编辑、上传、字体成品；字体索引、项目索引、配置与归档包保持原位置。桌面版提供系统文件夹选择，并从当前图片库位置开始；浏览器提供目录选择弹窗，支持常用位置、磁盘、面包屑、上一级和新建文件夹。路径只展示，不再要求输入。支持通过 localhost、电脑 IP 或应用域名访问；储存操作管理运行服务的电脑。局域网客户端模式提示到主机管理，不将清理请求代理到主机。请求来源按浏览器 Host 校验，兼容 Next 内部地址与反向代理地址不同的情况。

切换目录保留历史根路径读取。可仅更改后续写入，也可后台迁移现有图片；逐文件 SHA-256 校验，成功后移除旧文件。目标空间检查、同名冲突预检、临时文件、失败状态、重试入口和真实文件进度均已接入。任务状态保存在服务进程中，重启后需再次点击迁移，已落盘文件与旧目录回退配置仍有效。外置盘断开阻止新文件写入。

画布预览缓存上限为 64 MB–4 GB，使用现有按最早生成时间淘汰机制。字体缩略图支持手动清理和请求时重建。磁盘用量不包括独立归档目录及浏览器 HTTP 缓存。

扫描只处理图片库中的普通文件，不跟随文件符号链接。未引用清理只识别应用生成的命名，并有 24 小时保护期；遍历本机 JSON 索引保护项目、素材、字体、历史、任务引用。无法解析索引时终止扫描。此判断偏保守，疑似被引用文件予以保留。

扫描结果绑定用户、目录和 30 分钟有效期，执行时复查引用、文件签名和回收站状态。缓存保留最近一分钟文件。回收站只处理当前用户并保留共用文件；缺失原图仅报告。共享文件、文件变更等可能使实际释放量少于预估。
