# 输入框拖拽缩放与字体风格对齐

画布与字体创作底部输入框支持顶部调高度、两侧调宽度、上方两角同时调宽高。保持底部居中；左右缩放按中心对称。双击任意手柄恢复默认尺寸。手柄聚焦后支持方向键微调、Shift加速、Home重置；拖拽时Escape或失去窗口焦点恢复拖拽前状态。

两个模块独立保存宽、高偏好。保存操作发生在拖拽结束或键盘调整后，窗口缩小仅限制显示尺寸，不覆盖原偏好；窗口变大恢复偏好。自动高度仍保留，不强行写入固定尺寸。

采用Pointer Events、指针捕获和requestAnimationFrame更新局部DOM。画布图片、连线和生成任务不参与每帧React更新。ResizeObserver继续更新画布工具栏避让、字体作品滚动留白。输入框有最小尺寸、可用容器宽度限制和高度上限，参数按钮可换行，文字区域独立滚动。

选中字体风格后，卡片显示在输入框左侧，上下边界一致，选中图片保持比例；未选或移除风格时不显示占位、不预留空列。风格区宽度随可用窗口分档，输入框宽度调整时整体居中。卡片只保留更换和移除，不显示底部返回/撤销按钮。风格出现和隐藏会重新计算缩放边界，手柄始终贴合输入框，保留草稿、焦点和尺寸偏好。

验证覆盖两个模块的拖动/键盘/取消/重置/持久化、窗口收缩与恢复、文字编辑和弹层、已选风格对齐及未选风格收起，以及1440×960和1024×680界面。测试使用隔离本地数据，不请求外部生成接口。安装前检查普通与字体任务均空闲、备份最新数据、替换运行时后逐条核验。
