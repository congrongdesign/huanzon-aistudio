# 大画布布局与连线优化

## 实现

- 小组保留紧凑排列；大量同组图片按实际尺寸选择列数，每 16 张形成联系表，再将联系表按面积平衡横纵布局。无关联分组也按总面积扩展画布宽度，长编辑链分行。
- 有二次处理的浅层关系树按分支预留空间，编辑图跟随自身来源图，不再统一推到所有兄弟结果最右侧。多来源由首个有效父节点决定摆放，全部引用关系仍保留。超过 12 层的深链使用分阶段换行布局。
- 新生成批次优先在实际参考图附近搜索空位，兼容负坐标、画板边界与并发批次；图片工具处理同样按来源寻找位置，不因缩放扩大间距。
- 世界坐标中的连线路径缓存与视口分离；通过空间索引筛选可见路径和附近障碍。端点或相关障碍改变时更新对应线路；计算按约 4ms 时间片调度，切项目或新布局到来时取消旧计算。
- 普通线路集中在单一 SVG，每线一个 path；只有可见生成任务保留 Motif 流光（上限 12），拖动暂停光效。低于 40% 且超过 60 条关系时按来源与邻近区域聚合；选中或正在生成的关系保留具体线。
- 750px 屏幕预加载边距，平移超过 480px 才更新可见内容，松手提交最终位置；小幅平移复用 DOM transform。
- 质量、数量、比例为直接选择选项的独立按钮；分辨率、背景在适用模型下保留。删除审核、格式入口和重复对话模型选择，模型入口跟随创作模式。字体工作区同步独立按钮。
- 单张对话预览原比例显示，最大宽 220px、高 200px；双张各自保留比例，最大高 180px，不使用大幅扇形卡片。三张以上保留扇形与展开入口。

## 验证

- 自动测试：100/300/1000 同组混合比例图片、宽高平衡、非重叠、重复稳定；来源旁多分支编辑、循环/坏引用、长链；附近位置搜索；线路缓存复用、障碍移动/删除、空间索引与平移不重算。
- 隔离浏览器：100 图整理、撤销、刷新保存；300 图和完整 1000 关系场景；选择参数、模式对应模型、单图双图原比例和点击查看；窄窗口适配。
- 本机 Chrome 300 图拖动采样：旧版 p95 约 116.7ms，新版约 16.8ms。不是零延迟保证；仍有少量长帧。千图交互与算法测试通过，不代表任意设备/数据的固定帧率。
- 类型、修改代码 lint 和生产构建检查。保留项目中既有 lint 警告。
