# 环中AIStudio：竞品调研与100项功能候选

调研日期：2026-11-18（北京时间）。本次是公开资料案头调研，结合当前项目源码与近期本机验收文档；没有登录购买竞品、发起付费生成或访谈真实客户，不是完整的用户研究。没有修改平台业务代码或安装版。

## 一、先给产品判断

上一轮的问题是以“还能加什么”为出发点，列了很多辅助管理功能，没有先找到用户会反复完成、愿意为之付费的具体任务。

本轮看到最明确的共同方向是：**用户给原图、参考样式或现成内容，产品直接交付可使用的成品。** 美图、稿定都把商品套图、参考复刻、改字、商品替换、详情页放在明显位置；Recraft围绕矢量、风格复用、样机；Pixelcut强调批量处理；Napkin强调文字转可编辑图解。

对环中AIStudio，更值得验证的是“能直接完成设计任务”的专用流程：参考海报换内容、点字修改、品牌样机、信息图、成套图文、商品替换。它们能复用现有画布、字体、参考图、队列和导出链路。单独再造一套收藏、标签、评分、记忆管理系统，当前证据不足以支持优先投入。

不要把100项理解成100个主导航或100个独立开发项目。它们是候选任务，其中多个应合并在一个工作流内。首轮只验证3项。

## 二、证据怎么读

- **官方热门标记**：页面确实写了“热门/HOT”；这是官方推荐信号，不是独立统计的使用排行。
- **多家共同主推**：至少两家公开产品页面提供同类任务，说明供给侧持续投入，仍不能证明我们用户需要。
- **公开需求票数**：可查看的用户反馈；是局部样本，旧帖子和自选投票不能当全市场需求规模。
- **官方功能存在**：只证明竞品提供或宣传该功能，不证明效果、销量、使用量。
- **衍生候选**：从竞品能力推导到我们的设计场景；不冒充竞品已有功能或已验证需求。

没有查到公开的功能级DAU、付费转化率和留存数据，因此本文不称任何一项为“全网最热门”。

### 三条可直接复核的用户需求

1. [Camera angles：47票](https://feedback.recraft.ai/feature-requests/p/camera-angles)。用户明确列出俯拍、侧面、低角度等视角，2025年仍有追问。
2. [Reference image weight：18票](https://feedback.recraft.ai/feature-requests/p/reference-image-weight)。核心诉求是让参考控制生成方向，避免把参考内容直接混进成品。
3. [Editable vector SVG files：13票](https://feedback.recraft.ai/feature-requests/p/editable-vector-svg-files)。评论还指出具体痛点：希望容易修改指定颜色。帖子后来有人找到了现有色板能力，说明它也是功能可发现性问题，不能直接断言竞品缺少编辑能力。

## 四、我们已有的基础，以及不能想当然的地方

- 已有画布、多参考图、案例图与提示词回填、AI改图、局部蒙版、扩图、调色、历史与生成队列。新增任务应复用它们。
- 已有字体创作、字体库和Illustrator描摹。描摹输出是路径，不等于安装字体；不把它重新包装成“新增矢量描摹”。
- 已有三库导入、分类、备份、资源包，不再列“再做图库/标签/备份”为新点子。
- 已有图片/PDF转换和可编辑PPT导出相关基础。但部分历史PPT/批量模块已从当前入口移除；存在API和代码不等于本机现有入口可用。恢复或重建完整流程必须另行核查。
- `image-process`当前主要处理去背、高清、抠图、风格变换与普通AI改图，不是专用文字编辑、产品保真、真正图层编辑引擎。
- 参考图接口接受图片，不代表模型支持精确的数值权重、相机参数或种子控制。不能画一个滑杆就宣称具备控制能力。
- Sharp能做合成、裁切、缩放；不能单凭Sharp获得语义分割、真实阴影、3D贴图或文字识别能力。
- 字体、文字和数据可编辑优先；PPT不得用整页图片冒充可编辑对象，不得以自动缩字掩盖问题。

## 五、100项候选池

标记说明：**直**＝竞品公开列有同类任务；**衍**＝基于相关能力的场景延伸。并非每项都有独立热度证据，来源列是功能依据，不是热度排名。

实现路线：**复用**＝主要复用现有生图/改图与队列，但仍须验证成品质量；**开发**＝需要新编辑、布局、图像处理或批量交互；**外接**＝需要新增API或专门模型；**探索**＝高不确定性，暂不排期。难度是相对判断，不是工期承诺。

## 七、首轮只验证3项，不先建设大型新模块

建议首轮：**参考海报换内容、点中文字修改、设计稿贴样机**。三者共享真实输入，能串成“借鉴设计→改成自己的→看实际应用”的完整任务，而且更贴近现有画布、字体和案例库。

如果近期真实工作主要是提案和汇报，第三项改为“文字转可编辑信息图”；如果实际以店铺运营为主，则改成“商品主图套图”。这要由真实任务决定，不能因为竞品电商页面多就替用户选择电商定位。

### 验证设计

以下均为建议验收门槛，不是本次已达到的数据：

- 每项准备10–20个真实任务样本，覆盖容易和困难案例，先用现有工具记录人工耗时与返工次数。
- 找3–5位真正会完成这些任务的人试用；不能用功能开发者自己满意代替用户价值。
- 记录从导入到“愿意实际使用/交付”的总耗时、生成次数、外部工具补救次数与单次成本。
- 门槛建议：至少70%的样本达到可用或仅需轻微调整；相对现有方式中位完成耗时降低30%；关键文字/Logo不能静默改变。阈值应在试验前确认，避免看完结果再改口径。
- 专用流程需要明显优于直接在当前聊天框写一句提示词；若只是少打几个字，没有更好的控制、可靠性或批量交付，合并成快捷操作，不做独立模块。
- 点字修改若艺术字效果不稳定，首版明确只支持清晰印刷字；样机先限定可控模板；不要用范围模糊掩盖成功率。
- 外接API先做离线样本对比、确认价格与授权，再决定接入。公开API存在只证明有路线，不证明我们的效果、成本和可编辑要求已经满足。

## 八、明确暂缓什么

1. 完整视频工作台：新供应商、成本、时间线编辑、编码和存储均增加，超出当前最贴近的主流程。
2. 完整包装刀版与通用3D：Pacdora的专业能力不等于我们用生图就能交付制造文件。
3. 通用自由节点编辑器：先验证3–5步固定生产流程，有复用需求再开放节点。
4. “绝对主体一致”“任意相机角度准确复原”“任意字体完美替换”：目前没有测试证据支持这些承诺。
5. 再造图库、标签、备份、基本扩图与抠图：我们已有，缺点应该修好，不算新机会。
6. 直接恢复已移除的旧工作台和风格包：先明确现有入口与真实需求，避免把历史减法全部撤回。

## 九、可实现性的额外证据

- [Recraft API Quickstart](https://www.recraft.ai/docs/api-reference/getting-started)：存在生成、矢量化、去背、图像编辑等正式接口；矢量模型可返回SVG。
- [Recraft Styles API](https://www.recraft.ai/docs/api-reference/styles)：参考图创建可复用style_id，官方说明无需训练；不同模型兼容范围有要求。
- [Napkin API说明](https://www.napkin.ai/api/)：支持文字输入、异步生成、SVG/PNG/PPT输出；访问取决于账号token、额度和限流，不假设免费。
- [Pixelcut批量编辑](https://www.pixelcut.ai/bulk)：公开描述一次设参、批量执行、逐图修正、ZIP下载，是可参考的交互流程；不等于可调用其全部功能API。
