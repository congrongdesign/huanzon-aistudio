# 生成状态与输入交互精简

## 行为

- 普通画布和字体创作的生成框保留原有渐变加载动效，不显示“正在生成”等状态文字、九宫格符号和状态标签底色。提示词、说明、计时、取消按钮和重复的顶部生成提示均不显示。
- 点击普通生成框，按 Delete 或 Backspace 取消对应后台任务；字体生成卡同样支持点击后按删除键。输入框、输入法及弹窗内删字不会影响任务。
- 普通画布支持多选后同时取消任务、删除作品；引用图片仍调用参考图接口。撤销删除不会恢复已取消任务。
- 取消发生在提交阶段时，收到服务端任务编号后仍发送取消；等待阶段会停止轮询。服务端取消状态不会被迟到结果覆盖，取消的图片记录不重新出现在画布中。
- 输入框移除质量、背景按钮。质量在提交时按实际模型取最高合法值，旧字体草稿的低质量配置不会影响新任务。分辨率与比例选择保留，默认16:9、4K优先策略不变。
- 中间输入栏提供“提示词”按钮，向上展开带搜索和分组筛选的浮层。选择后追加文字并保留当前参考图；支持 Escape、点击外侧和关闭按钮收起。右侧对话记录不再承担提示词选择功能。
- 输入框内900毫秒内连续按两次 ↑，恢复当前项目上次发送的文字与参考图。字体创作恢复本设计上次发送的个人要求与参考图。单按、长按、带修饰键、输入法候选导航不触发，其他按键会打断连续操作。
- 每个普通项目、每个字体设计恢复一次后，连续 ↑ 保持正常光标导航，不再覆盖输入；修改文字、清空、切换项目后返回均不会解除本次锁定，下一次发送新内容后重新允许恢复。
- 普通项目刷新后的恢复来源为该项目最后一条用户消息，项目之间隔离；字体设计保持独立。

## 实现

画布和字体创作不再向 `GenerationOverlay` 传入生成状态标签，移除对应组件及标签样式，保留图片解码完成后的淡入与加载失败反馈。`LoadingState` 继续用于文本回复等其他模块；`composer-recall.ts` 集中处理快捷键判定。`CanvasComposer` 内的 Radix Popover 复用现有提示词分组与搜索组件。画布键盘删除分流至任务取消、参考图删除及成品删除。

普通任务前后端按模型规范质量，字体生成接口按实际模型规范质量。取消流程同时覆盖排队、运行和提交时序；服务端将取消图片记录标为取消并软删除，阻止项目重载后回流。

## 验证

类型检查、变更文件 lint、生产构建；任务队列与取消时序、默认质量和快捷键逻辑测试。界面在隔离数据与本地模拟模型下验证，不调用付费模型。详细截图和安装前数据备份保存在本轮工作区备份目录。
