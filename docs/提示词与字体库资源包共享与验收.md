## 使用

两个库右上角提供「导入」「导出」。导出支持整个库、按分组、搜索选择条目；输入名称，可选作者与说明。生成 `.hzlib` ZIP 文件，经微信、邮件或共享文件夹传给同事，在对应库导入。

桌面端使用本机保存通道，写入设置中的下载目录（未设置时使用系统下载目录）。确认文件保存成功后显示完整路径，可「打开所在文件夹」或「另存一份」；重名文件自动编号，保存错误可重试。

macOS 的 `.hzlib` 文件使用软件 Logo，系统类型名称为「环中AIStudio资源包」。通过库内「导入」打开预览。打包配置声明 `com.huanzon.aistudio.library` 文件类型，手工组装脚本同步注册；本机安装应用已原位更新、重新签署并刷新 LaunchServices。实际桌面导出后通过 NSWorkspace 读取文件图标，确认显示现有软件 Logo；系统类型与描述解析正确。

补充复验：仅 NSWorkspace 返回 Logo不足以证明 Finder实际显示正确，已复现 Finder仍显示白纸。已修正声明为 Viewer，并在桌面保存流程通过 NSWorkspace为 `.hzlib` 写入现有 Logo自定义图标；Finder实际截图确认显示 Logo，用户反馈“可以了”。自定义图标依赖 macOS扩展属性，跨平台或某些传输方式可能丢失，不能承诺无安装接收端自动显示 Logo。Windows运行时图标另见打包规范中的待办，待后续统一打包验收。

导出包含实际图片。提示词保留正文、标题、标签、子分类、效果图、相关参考图及公开来源信息；字体保留成品图、参考图顺序与标签、提示词、原提示词、示例文字、风格、说明和已记录的生成参数。字体库共享内容是设计案例，不是 TTF/OTF 字体安装包。

导入先校验并预览条目数、图片数、图片大小、缺失图片、重复内容和同名/版本冲突。目标可选择新建分组、原包分组结构、已有分组。同名新分组自动编号。重复跳过，本地改动保留，发生冲突另存一份。导入结果可见新增/跳过数，并自动定位新建或选定分组。

## 实现

- 移除已废弃 `/api/prompt-export`，新接口 `/api/library-transfer`。
- `library-transfer.ts` 为两个库提供统一格式、资产收集、校验、预览、去重和导入；`LibraryTransfer.tsx` 为共用界面。
- 清单格式 `huanzon-library`、版本 1；包含 records 与 groups，图片存于 `assets/<sha256>.<ext>`。每个包内按内容散列复用图片。
- 不导出账号、数据库原始编号、API 配置、个人项目关联或运行记录。接受者生成新编号、建立本机图片地址；稳定来源身份及内容版本用于再次导入和转发检测。
- 逐文件受限读取 ZIP，不提取任意路径，限制压缩包、文件数量、单图、解压大小；校验图片散列、解码格式、引用关系和包类型，拒绝未知版本。
- 单包最多10000条，实际图片总量256MiB，文件上限264MiB，单图25MiB；支持静态 PNG/JPG/WebP。超过限制可按分组拆包。
- 上传显示进度；图片收集、校验、保存期间显示工作状态。导出使用分块响应与字节读取，避免 Electron 大 Blob 响应读取失败。
- 同一用户、同一库的导入串行。字体条目与分组在原索引锁内一次提交；提示词条目一次提交，分组创建失败路径会回收本次分组。图片保存失败会清理本次新建文件。进程被强制终止时可能残留未引用图片/空分组，不宣称跨文件系统事务。
- 本版共享采用独立副本，不提供云端订阅更新或导入批次撤销。原有资源不被导入覆盖。
