# 平台完善计划文档（V2）

## 1. 本轮改造目标

1. 完成 PPT 工作台全链路重构（风格确认 -> 自动美化 -> 审核 -> 导出）。
2. 统一浅色/深色 UI 风格，降低视觉割裂。
3. 修复生成失败反馈体验，防止聊天区域噪音堆叠。
4. 输出可持续迭代的功能规划（参考 Lovart 式体验）。

---

## 2. 已完成（本次）

1. 工作台风格确认
- 每个风格方案支持独立参考图集合。
- 支持方案级补充提示词。
- 支持方案重生成。

2. 风格锁定
- 确认方案后生成 `styleLockPrompt`。
- 批量阶段统一继承锁定风格，减少风格漂移。

3. 自动美化
- 默认跳过封面/内页样张页（可逐页取消）。
- 每页支持单独附加提示词。
- 每页支持原稿预览。

4. 并发与进度
- 批量任务改为并发池执行（2~16可调）。
- 显示总任务进度、运行中任务数、失败数、ETA。

5. 审核增强
- 增加审核过滤（全部/待审核/失败/已通过）。
- 增加“单方案重生”能力。
- 保留“单页重生”。

6. 失败体验修复
- 生成失败不再写入聊天堆积文本。
- 失败由画布失败卡和页面状态承载。

7. UI 统一
- 增加全局 light/dark 样式桥接。
- 提升浅色模式关键区域对比度。

## 3. 下一阶段优化（建议自动继续）

## P1：生成引擎增强

1. 后端队列化（可选）
- 将前端并发池进一步下沉到后端 worker，提升稳定性。

2. 任务恢复
- 页面刷新后恢复批量任务状态（继续排队/继续轮询）。

3. 智能重试
- 对不同错误分类（429/5xx/内容审查）分级重试策略。

## P2：审核体验升级

1. 双栏对照常驻（原稿 vs 当前方案）。
2. 多方案快速切换快捷键（1/2/3/4）。
3. “一键通过本页最佳方案”智能建议。

## P3：资产与风格体系

1. 风格模板库（可保存/复用/共享）。
2. 参考图自动聚类（色系/材质/构图）。
3. 页面类型自动识别更细分（封面/章节页/图表页/团队页等）。

## P4：协作能力

1. 局域网协作任务看板（谁在审哪页）。
2. 审核意见批注（页级评论）。
3. 审核流转状态（待你审核/待同事审核）。

---

## 4. 风险与控制

1. 并发过高触发限流
- 控制：动态降并发 + 指数退避。

2. 文字一致率要求高导致失败率高
- 控制：严格模式可切换；失败页集中复审。

3. 超长项目（60~100页）中断风险
- 控制：推荐按 10/20 页分段执行。

---

## 5. 验收指标（量化）

1. 40页项目：平均总耗时较改造前下降 >= 35%。
2. 审核阶段：首次可见方案时间 <= 10s（有并发时）。
3. 主题切换：关键页面文字对比稳定，无明显不可读点。
4. 失败反馈：聊天区错误噪音减少 >= 80%。
