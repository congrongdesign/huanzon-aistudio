# 环中AIStudio v0.2.0

> AI 设计画布工具：与 AI 对话协作，在无限画布上创建、编辑和管理图像设计。
> 灵感来自 Lovart.ai 的 ChatCanvas 交互范式。

## 一、功能模块介绍

### 1. AI 对话画布（核心）
- 左侧对话面板直接描述需求，AI 生成图片并实时落到画布
- 支持选中画布图片作为参考图，在对话中引用（`@引用图片`）
- 一次可生成 1 / 2 / 4 / 8 / 16 张，批量结果自动分组展示
- 支持多模型对话（GPT-4o / Gemini / Claude / DeepSeek 等，OpenAI 兼容接口）
- 生成过程可取消，失败提示留在画布上

### 2. 无限画布
- 拖拽 / 滚轮缩放 / 空格平移 / 框选 / Shift 多选
- 快捷键：`Ctrl/Cmd+Z` 撤销、`Ctrl/Cmd+D` 复制、`Delete` 删除、`Esc` 退出模式
- 图片工具栏：扩图、去背景、高清放大、分层、抠图、引用、下载
- 画板（CanvasBlock）：把图片收进画板自动整理、重命名、锁定、缩放
- **整理画布**：一键按“派生关系 / 生成批次 / 提示词”分组整理；内容超过约 2 屏高度时自动横向另起一列，避免画布无限变长
- **自动适配**：打开软件或切换项目时，自动以最合适的缩放比例把项目全部内容完整显示在可视区域内
- 支持拖拽 / 粘贴 / 剪贴板导入图片

### 3. 作品图库
- 分页加载（80 张/页）+ 滚动渐进渲染，千张级图库流畅滚动
- **服务端缩略图**：卡片加载 WebP 缩略图（约原图 1/80 体积），原图仅在大图预览/下载时加载
- 自适应 / 网格 / 瀑布 / 列表四种视图，缩略图大小可调
- 标签管理、收藏、按项目 / 比例 / 色调 / 模型 / 关键词筛选
- 详情面板：提示词、色彩分析、直方图、标签、生成参数
- 批量下载（ZIP）、Lightbox 全屏查看（滚轮缩放）
- 回收站：恢复 / 永久删除 / 清空，操作即时响应，卡片按真实比例显示

### 4. 模型中心
- 模型表格：列可显隐、拖拽列宽（只动当前列、2px 细线手柄）、悬停查看完整说明
- 多供应商接入：gr sai / 云雾 / Codia 能力目录 / 自定义中转站
- 模型分类识别（生图 / 文本 / 视频 / 视觉理解…），能力路由
- API 配置：Base URL + API Key、连接检测、模型广场、常用端点快捷切换

### 5. 提示词资产平台
- 提示词库、实验室、原子词、组合包、业务模板、分类管理
- 提示词检索、测试记录、导出/导入、版本历史
- 全屏 PromptManager 工作台

### 6. 项目管理与同步
- 项目列表：新建、重命名、置顶、删除、文件夹
- 云同步中心：NAS / 本地目录双向同步项目包与版本，多机恢复
- 项目导入 / 导出（项目包）、自动备份
- 云同步弹窗仅通过“×”手动关闭，拖拽到窗外不会误关

### 7. 桌面体验
- **多显示器 / 多分辨率自适应**：按窗口尺寸自动缩放（设计基准 1440×900），小屏自动缩小防滚动、大屏不超过设计原大小；支持 `⌘/Ctrl +/-` 手动微调并记忆
- 深色 / 浅色主题，全局画布网格
- 本地优先架构：数据保存在本机，支持 NAS 同步

## 二、v0.2.0 更新内容

**新增 / 改进**
- 打开软件、切换项目时自动适配画布，完整显示全部内容（最合适缩放比例）
- “整理画布”改为分列布局：超过约 2 屏高度自动横向另起一列，列间距 120px，超大分组自动拆段
- 作品图库性能大优化：服务端 WebP 缩略图链路 + 内存 LRU 缓存、图片自然尺寸批量更新（消除滚动卡顿）、懒加载 + 异步解码
- 模型表格拖拽列宽优化：只改变被拖列、2px 细线手柄、拖动中锁定光标与文本选择、Esc 取消
- 模型列表“说明”悬浮即时显示完整内容（不再等原生 title 1 秒）
- 回收站：删除/清空即时响应（乐观更新），卡片按真实宽高比显示（不再全是正方形）
- 云同步中心弹窗不再因“按住拖到窗外”误关闭，仅通过 × 关闭

**精简（移除冗余功能）**
- 移除启动页“本机体验 / 同 WiFi 协作 / 好友 / 消息”、互联按钮
- 移除“节点画布”功能及代码
- 移除画布“新建画板”入口（已有画板的管理功能保留）
- 移除“工作台”功能

## 三、安装说明

- **macOS（Apple Silicon）**：下载 `环中AIStudio-0.2.0-arm64.dmg`
- **macOS（Intel）**：下载 `环中AIStudio-0.2.0-x64.dmg`
- **Windows x64**：下载 `环中AIStudio-0.2.0-win-x64-setup.exe`（安装版）或 `环中AIStudio-0.2.0-win-x64-portable.exe`（免安装）
- **源码**：`环中AIStudio-0.2.0-source.tar.gz`

> 未签名说明：本项目未使用正式签名证书，macOS 首次打开会出现 Gatekeeper 提示、Windows 会出现 SmartScreen 提示，属正常现象。
> - macOS：右键应用 → 打开；或 系统设置 → 隐私与安全性 → 仍要打开
> - Windows：更多信息 → 仍要运行

安装后首次使用请在“模型中心”配置 Base URL 与 API Key（支持 gr sai、云雾、Codia 或任意 OpenAI 兼容中转站）。

## 四、数据与隐私

- 数据默认保存在本机应用数据目录，不强制上传云端
- 可通过“云同步中心”将项目包同步到 NAS / 本地目录
- 图片记录、对话记录、提示词资产均本地存储（支持 Supabase 云模式，默认关闭）

## 五、校验

所有安装包 SHA-256 见 `SHA256SUMS.txt`，校验示例：

```bash
shasum -a 256 环中AIStudio-0.2.0-arm64.dmg
```
