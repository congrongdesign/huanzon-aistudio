# 环中 AIStudio UI 规范

版本：v3.0 · 2026-11-13。适用：画布、提示词、字体、资产、模型及相关弹层。本文替代此前紫色玻璃风格规范。

## 设计基础

采用 Motif 的中性表面、细边框、紧凑排布和克制动效。作品图像为主体，红、绿、琥珀只表达真实状态。保持五个工作区；不恢复已移除的图库、转换、技能等导航。

实现位于 `src/app/globals.css` 的 Motif platform language 段。新组件使用语义 token，不继续扩展旧颜色兼容映射。主按钮搭配 `text-primary-foreground`，普通选中使用浅背景、文字与勾选。

## 通用组件

- `ui/motif/`：保留 MIT 来源的 Message、Attachment、StrengthSlider；第三方说明见根目录 `THIRD_PARTY_NOTICES.md`。
- `ui/neutral-select.tsx`：Radix Portal + cmdk 菜单；搜索、分组、方向键、Esc、当前选择，值保持原业务 ID。
- `creation/CreationControls.tsx`：模型选择、参数入口、比例网格与参数行。
- `creation/GenerationState.tsx`：真实任务状态、九点等待标记、局部计时。每张卡只订阅自己的任务。
- `platform/Settings.tsx`、`SettingsDialog.tsx`：分区、表单行、空状态与分类弹窗。表单草稿由业务外层持有。
- `CanvasPreviewImage.tsx`：分辨率适配预览、失败回退原图、解码后短淡入；加载图片不发起生成请求。

## 排布与文字

4/8px 间距节奏，区块常用 16/24px。内容 12–14px，辅助文字 11–12px，窄导航标签至少 10px。输入和菜单圆角 8–12px，弹窗 16px；减少多层卡片和重复标题。

模型和生成参数放在输入附近；顶部保留项目和视图。提示词保留一级分组，新建按需展开，长文以摘要开头。字体保留独立会话和全局资料。字体/案例成品完整 `contain` 展示。

窄窗资产详情可收起，模型配置成为侧边面板；设置分类转为横向导航。弹窗与菜单通过 Portal 呈现，避免被工作区 overflow 裁切。

## 交互语义

“追加到输入”和“替换输入”明确区分。字体风格替换只换风格配方，个人输入与个人参考图不被清空。模型 ID 与服务 ID 一起保存；不把同名模型合并成一个未知来源选项。

发送期间输入仍可用。输入法组合 Enter 不提交；图片粘贴与上传共用流程；引用数量超限时保留输入并明确反馈。文字停止按钮只取消对应回复，生成取消不暗示已停止上游计费。

对话仅在用户位于底部附近时跟随；向上阅读后出现“回到最新”。保存、上传、任务失败显示在对应局部，不全局锁屏。

## 动效与可访问性

悬停 140ms、菜单 160ms、图片揭示 220ms。避免大面积 blur、无限位移动效、等待动画结束才能操作。任务状态来自真实队列，不按经过时间虚构阶段或百分比。

尊重 `prefers-reduced-motion`；后台文档暂停等待动画和计时刷新。可见焦点环、键盘菜单、弹窗焦点恢复、可读标签、触屏操作入口为基础要求。

## 验收

功能与视觉分别验证；覆盖浅/深主题、常用窗口与窄窗、空/加载/失败/成功、多任务同时运行。测试隔离用户数据，付费调用使用模拟服务；实际付费生图未运行时如实记录。验收清单见 `Motif改造验收清单.md`。
