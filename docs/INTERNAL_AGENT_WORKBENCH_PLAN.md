# 环中AIStudio 内部 Agent 工作台规划

## 目标

把 Open Design 的 Agent 驱动思想改造成适合团队内部使用的能力：不做公开插件商城，不重构现有画布，只增加本地能力检测、内部 Agent 中心、结构化任务拆解、PPT 工作台自动化增强、任务恢复和评审机制。

## 总体原则

1. 保留现有画布、PPT 工作台、资产库、模型配置，不推倒重来。
2. 所有 Agent 能力先做成内部预设，不开放第三方插件市场。
3. 任何自动执行都必须有明确状态、进度、失败提示和可人工接管路径。
4. 长任务必须持久化，刷新页面后能看懂上次做到哪里。
5. 非技术用户只看到“可用 / 未配置 / 点击配置”，不暴露命令行细节。

## 阶段拆解

### 阶段 1：本地能力检测

任务：
- 新增 `/api/local-capabilities`，检测本机是否具备常用工具。
- 检测 Codex、Claude、Gemini、Qwen、Ollama、ComfyUI、LibreOffice、Poppler、Node、pnpm。
- 检测 NAS / 飞书配置是否存在。
- 返回用户友好的状态、说明、下一步建议。

验收：
- 设置页或 Agent 中心能看到本机能力检测结果。
- 未安装项不会报错，只显示“未检测到”。
- 检测失败不会影响主应用启动。

风险与规避：
- 风险：不同系统命令路径不一致。
- 规避：使用 `command -v` / `which` / 常见路径组合，失败时降级为未检测到。

### 阶段 2：内部 Agent 中心

任务：
- 新增 Agent 中心入口。
- 内置 6 个团队 Agent：PPT 美化导演、资产检索员、提示词工程师、设计评审员、画布执行员、交付打包员。
- 每个 Agent 显示能做什么、需要哪些能力、当前是否可用、推荐下一步。
- 支持一键进入 PPT 工作台、资产库、模型配置。

验收：
- 用户能从左侧导航打开 Agent 中心。
- Agent 卡片可读、可操作、不会要求用户懂代码。
- 本地能力检测结果能影响 Agent 可用状态。

风险与规避：
- 风险：做成虚假的聊天入口，实际不可用。
- 规避：第一版只承诺可执行的工作流入口和任务拆解，不假装拥有未实现工具。

### 阶段 3：PPT 任务拆解与结构化 Brief

任务：
- 在 PPT 工作台增加“Agent 任务拆解”侧栏。
- 把任务拆成：导入原稿、整理需求、检索参考、生成风格、自动美化、自动评审、审核导出。
- 增加结构化 Brief 字段：场景、受众、风格、约束、参考来源、禁止事项。
- 保留当前自由文本提示词，Brief 自动合并为提示词上下文。

验收：
- 用户上传 PPT 后能看到下一步清晰指引。
- 用户可以一键套用风格预设和任务模板。
- 不填写 Brief 也不阻断老流程。

风险与规避：
- 风险：强制表单让流程变复杂。
- 规避：只做推荐表单，不填写也可继续。

### 阶段 4：风格预设库与自动评审

任务：
- 增加内部风格预设库：科技发布会、高端商务、国风文化、教育培训、品牌提案、极简高级。
- 每个风格包含颜色、排版、装饰密度、提示词片段、反向约束。
- 为每个生成方案显示自动评审卡：文字完整、风格一致、排版层级、清晰度、风险提示。

验收：
- 风格确认阶段能一键选择风格预设。
- 审核阶段每个方案都有易读评审结果。
- 不影响原有重生、确认、导出按钮。

风险与规避：
- 风险：评审依赖模型会增加成本。
- 规避：第一版先做规则评审 + 已有文字校验结果，后续再接模型评审。

### 阶段 5：任务恢复与运行安全

任务：
- 持久化队列状态、当前阶段、进度、失败项、最近更新时间。
- 打开 PPT 工作台时提示“发现上次未完成任务”。
- 提供继续、查看失败项、重置状态三个安全入口。

验收：
- 页面刷新后能看到上次任务状态。
- 失败项不会变成一堆不可读文字。
- 用户能手动重试失败页。

风险与规避：
- 风险：后台请求已经断开，无法真正继续同一个请求。
- 规避：恢复的是任务清单和已完成结果，未完成项重新排队生成。

### 阶段 6：飞书 / NAS 知识联动增强

任务：
- Agent 中心展示 NAS 和飞书是否已配置。
- PPT 工作台支持从资产库选参考图。
- 后续可根据 Brief 自动检索知识库资料。

验收：
- 用户知道当前资料源是否可用。
- 没配置飞书时不影响本地 NAS 工作流。

风险与规避：
- 风险：飞书权限复杂。
- 规避：只读取已配置知识库，不做组织级自动授权。

## 当前实现范围

本轮落地：
- 阶段 1 本地能力检测。
- 阶段 2 Agent 中心入口。
- 阶段 3 PPT 任务拆解与结构化 Brief 基础版。
- 阶段 4 风格预设和规则评审基础版。
- 阶段 5 任务恢复提示基础版。

暂不实现：
- 公开插件商城。
- 完整 CLI 引擎重构。
- 自动调用外部 Agent 修改项目文件。
- 后台常驻任务守护进程。

## 成功标准

1. `pnpm ts-check` 通过。
2. 原画布、图库、资产库、PPT 工作台仍能打开。
3. Agent 中心能显示本机能力和内部 Agent 卡片。
4. PPT 工作台能看到 Agent 任务拆解、Brief、风格预设、恢复提示。
5. 所有新增功能不依赖服务器，不影响本地模式。
