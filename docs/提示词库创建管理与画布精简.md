# 提示词库创建管理与画布精简

## 范围
移除画布右上 Key 状态入口与底部缩放浮条；设置中的模型配置、画布手势缩放及右键整理仍可使用。

## 信息与交互
- 保持单层分组：全部、未分组、用户分组，显示条目数。
- 新建入口放在内容工具栏，与当前列表标题同一行；不占用全局页头。
- 新建和编辑使用同一窗口：正文、所属分组、取消、保存。支持 Cmd/Ctrl+Enter，空白正文禁止提交，最多 30000 字符。
- 列表支持搜索、复制、编辑、删除、移动分组与使用提示词。长正文折叠，按需展开。
- 分组可新建、改名、删除；删除分组后正文保留到未分组。
- 有修改时关闭窗口提供继续编辑、保留草稿、放弃修改。草稿存于当前会话的 sessionStorage，可在刷新后恢复；不声称跨设备或跨应用重启同步。
- 保存失败显示原位错误并保留正文；删除失败在确认窗口内显示。

## 实现
沿用 Motif 主题变量与 Radix 的焦点、键盘及弹层机制，不新增依赖。提示词编辑复用 PATCH /api/prompts，更新原记录，未提供分组时保持原分组；所有权校验沿用服务端机制。主题主按钮使用局部组件规则，避免旧主题的通用 button 颜色覆盖。

## 验收
在隔离数据中验证深浅主题、键盘保存、创建/编辑/移动/使用、分组保留、取消删除、草稿恢复、失败重试与小窗口布局。完成类型检查、针对修改文件的 ESLint、生产构建。安装前备份最新用户数据，确认无运行任务后仅重启 AIStudio。
