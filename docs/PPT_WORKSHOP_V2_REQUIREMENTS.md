# PPT 工作台 V2 需求文档（重构版）

版本：v2.0
日期：2026-05-31
目标：把当前“可用但不稳定”的流程，升级为“可批量、可并发、可追踪、可审核”的生产级工作台。

---

## 1. 背景与问题

当前工作台的主要问题：

1. 风格确认阶段：参考图逻辑不清晰，用户需要“每个风格方案独立参考图”，而不是共用。
2. 风格落地阶段：批量生成结果和已确认风格不一致，风格锁定不足。
3. 自动美化阶段：缺少单页补充提示词入口，且看不到该页原稿，不利于精细控制。
4. 流程重复：封面页和内页样张在 style 阶段已确认，generate 阶段仍重复生成，浪费时间。
5. 进度反馈弱：缺少实时进度、并发状态、预计剩余时间（ETA）。
6. 审核展示延迟：生成完成后预览刷新不及时，造成“已生成但看不到”的体验断层。
7. 性能利用不足：模型支持高并发，但当前生成节奏偏串行。

---

## 2. 产品目标（V2）

1. 风格方案独立：每个方案都能配置自己的参考图集，并保证参考图实际参与生成。
2. 风格一致性：批量阶段强制继承“已选风格方案”的核心视觉特征。
3. 自动化可控：一键启动批量，同时支持单页微调（提示词）和原稿预览。
4. 高并发提速：最大并发图生成能力提升到 16（受模型/账户限制时自动降级）。
5. 可视化进度：全局进度、每页进度、方案进度、失败重试、ETA 全展示。
6. 审核可追踪：生成结果及时出现，可单页重生、单方案重生、整批补生。

---

## 3. 关键流程（用户视角）

### 3.1 风格确认阶段（Style）

1. 用户上传 PPT/图片包后进入风格确认。
2. 系统自动抽取“封面页 + 内页示例页”。
3. 用户配置 `N` 套风格方案（N=2~6）：
   - 每套方案必须有独立参考图来源（可空，但不推荐）。
   - 每套方案可附加独立描述词。
4. 点击“生成风格方案”：每套方案生成“封面样张 + 内页样张”。
5. 用户审核并选择 1 套作为“锁定风格”。

### 3.2 自动美化阶段（Generate）

1. 进入批量前自动识别：
   - 封面页（page 1）与内页样张页（style 阶段所用 inner page）已确认，则默认跳过。
2. 用户可设置页码范围（如 1-10、11-20、全部）。
3. 每页生成 4 个方案（默认，可配 2/3/4/6）。
4. 每页支持填写“单页附加提示词”。
5. 每页可随时查看原稿缩略图/放大预览。
6. 任务启动后并发执行（最大并发 16），并显示总进度与 ETA。

### 3.3 审核阶段（Review）

1. 列表实时显示每页状态：排队、生成中、待审核、失败、已通过。
2. 每页显示 4 个方案卡片，图片边生成边展示。
3. 可执行：
   - 选中最终方案。
   - 重生本页（全部方案）。
   - 重生单方案。
4. 支持过滤：仅看失败页、仅看待审核页、仅看已完成页。

## 4. 功能需求（详细）

## FR-01 风格方案独立参考图（强制生效）

- 每个 `StyleProposal` 必须维护自己的：
  - `referenceImages: string[]`
  - `styleExtraPrompt: string`
- 执行该方案生成时，引用顺序：
  1. 原稿页面图（封面/内页）
  2. 当前方案 referenceImages
  3. 项目全局参考图（可选兜底）
- UI 要求：
  - 每个方案卡内显示“已配置参考图数量”。
  - 支持从 NAS/飞书/本地资产库选图。

## FR-02 风格锁定并继承到批量生成

- 用户确认某个方案后，系统生成 `styleLock`：
  - 调色倾向、构图语气、装饰密度、字体氛围（通过结构化提示词表达）
- 批量生成每页 prompt 组成：
  - `styleLockPrompt` + `pageRolePrompt` + `globalPrompt` + `perSlidePrompt`
- 禁止在批量阶段随机漂移风格：
  - 所有页面必须显式注入 `styleLockPrompt`。

## FR-03 自动跳过已确认样张页

- 在 generate 阶段默认 skip：
  - `coverPageNumber`
  - `styleInnerPageNumber`
- UI 提示：
  - “已自动跳过风格确认样张页（封面/内页）”。
- 可手动取消跳过（高级开关）。

## FR-04 单页提示词与原稿预览

- 每个 slide 新增字段：
  - `perSlidePrompt?: string`
- 生成面板新增“页面队列表”：
  - 左侧显示页码、状态、原稿缩略图。
  - 右侧可编辑该页附加提示词。
- 点击页卡可放大查看原稿。

## FR-05 高并发队列（最大 16）

- 新增前端队列调度器（Promise Pool）：
  - `maxConcurrency` 默认 8，可上调至 16。
  - 单页内 4 方案可并发。
  - 多页并发与单页并发共享池，避免过载。
- 限流与降级：
  - 连续429/5xx时自动退避（指数退避）并降低并发。

## FR-06 实时进度与 ETA

- 全局统计：
  - `totalTasks`, `completedTasks`, `failedTasks`, `runningTasks`
- 每页统计：
  - `slideCompleted/slideTotal`
- ETA 算法：
  - 基于最近 K 个任务平均耗时滚动估算。
  - `etaSec = avgTaskDuration * remainingTasks / effectiveConcurrency`
- UI 展示：
  - 顶部总进度条 + 文本“预计剩余 xx 分 xx 秒”。
  - 每页显示微型进度条。

## FR-07 审核阶段刷新与展示稳定

- 每次方案完成后立即写回对应 slide/proposal 状态。
- 审核列表按状态实时排序（待审核优先）。
- 失败卡片显示错误原因与重试按钮。
- 图片采用渐进加载：
  - skeleton -> 缩略图 -> 高清图。

## FR-08 失败自动重试

- 每个 proposal 默认自动重试 2 次。
- 文本校验失败（text_mismatch）可按策略：
  - 自动再生 1 次（可配置开关）。

## 6. 非功能要求

1. 性能：40~60页规模下，任务调度不卡 UI；100 页上限可分批稳定执行。
2. 可恢复：页面刷新后可从本地存档恢复任务状态（至少恢复结果，不强制恢复进行中请求）。
3. 可观测：日志可查看“页码-方案-耗时-错误原因”。
4. 兼容：本地模式/在线模式均可工作。

## 7. 里程碑计划（实施顺序）

## M1（1-2天）：流程结构重构

- 引入 `styleLockPrompt`。
- 风格方案独立参考图改造。
- generate 阶段自动跳过封面/内页样张。
- 单页提示词字段与 UI。

## M2（1-2天）：并发与进度系统

- Promise Pool（最大16并发）。
- 全局进度、每页进度、ETA 计算。
- 失败重试、降级策略。

## M3（1天）：审核体验修复

- 审核列表实时刷新。
- 失败原因透出。
- 单页/单方案重生。
- 预览加载体验优化（skeleton + lazy）。

## M4（0.5-1天）：联调与验收

- 用 10页/40页/60页 三组样本压测。
- 修复边界问题。
- 输出操作说明。

---

## 8. 验收标准（你可直接验）

1. 风格确认里，每个方案可单独选参考图；不共用也能生效。
2. 选定风格后，批量结果风格统一明显，不再漂移。
3. 自动美化不重复处理封面与内页样张（默认）。
4. 自动美化面板可逐页加提示词，并能看到原稿预览。
5. 生成过程可看到实时进度与预计剩余时间。
6. 审核阶段图片及时出现，失败页有原因、可重生。
7. 并发提升明显（同样页数总耗时显著下降）。

---

## 9. 风险与对策

1. 模型侧限流（429）
- 对策：自动退避 + 动态降并发（16->12->8）。

2. 参考图过多导致速度慢
- 对策：每次生成限制参考图数量（如最多4张），并在 UI 给建议。

3. 文字严格一致导致失败率高
- 对策：严格模式开关可调；失败自动重试并提示风险页。

4. 长任务中断
- 对策：分批处理（10/20页）+ 阶段保存，降低一次性失败成本。

---

## 10. V2 与当前版本差异总结

1. 从“串行脚本式生成”升级为“并发队列式生产流水线”。
2. 从“全局参考图”升级为“方案级参考图 + 风格锁定”。
3. 从“黑盒等待”升级为“进度可视 + ETA + 失败可处理”。
4. 从“后验审核”升级为“生成过程即反馈、审核可快速闭环”。
