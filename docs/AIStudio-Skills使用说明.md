# 环中AIStudio：提示词采集与字体设计采集两个 Skill

适用：Windows 10/11 x64、macOS；环中AIStudio v0.2.4+ 本机模式。Skill 安装在 Codex 中，软件里的“自定义技能”是另一套功能。此包只含采集工具和规则，没有发布者的项目、图库、API Key 或账号。

## 让 Codex 安装

将本压缩包保存到电脑，交给本机 Codex 并发送：

> 请解压附件，阅读使用说明，将 curate-design-prompts 和 curate-font-designs 两个目录安装到我当前 Codex 的用户技能目录。检查 CODEX_HOME；若已配置则用其 skills 子目录，否则用当前用户 ~/.codex/skills（Windows 通常是 %USERPROFILE%\.codex\skills）。不要覆盖同名的用户自改文件，先比较差异并保留自改部分。核对每个目录根部有 SKILL.md，检查脚本与引用完整。完成后告诉我实际安装路径，以及是否需要重新打开 Codex 才能发现技能。不要装到 AIStudio 的 /api/skills，不要复制发布者配置。

安装器不是必需的；也可以手动复制两个文件夹（不是整个外层目录）到当前 Codex 用户 skills 目录。若当前 Codex 的设置/文档指定了其他技能发现目录，以实际配置为准。官方参考：https://developers.openai.com/codex/skills/ 。本次打包时该页返回 HTTP 403，未据此宣称所有 Codex 版本均即时自动发现；请在接收端确认技能已出现在可用列表，必要时重开 Codex。

## 提示词采集：curate-design-prompts

适合收集已有真实提示词与对应效果图，保留来源、完整中文内容、分类和标签。

直接给 Codex：

> 用 $curate-design-prompts 收集10条适合发布会PPT的玻璃折射背景提示词，优先中文，逐条核对原文和对应效果图，整理进我正在使用的环中AIStudio提示词库。保留原有条目与删除状态，不调用付费生成。

也可以给具体网页：“用 $curate-design-prompts 把这个链接的案例整理入库：<网址>。”

## 字体设计采集：curate-font-designs

适合从作品页采集标题字设计参考，逐款裁图、备注字形材质和来源。它不安装 TTF/OTF 字体，也不把图片变成字体文件。

直接给 Codex：

> 用 $curate-font-designs 找20款暗黑幻想的中文标题字设计，一张卡片一个完整设计，补齐文字、风格、材质、用途、作者和来源，整理进我正在使用的环中AIStudio字体库。不要重复或恢复我删过的条目，不发起付费生成。

也可给作品网址：“用 $curate-font-designs 把此作品里的独立标题设计逐款整理进去：<网址>。”

## 使用过程与预期结果

先启动实际安装的环中AIStudio。Codex 使用接收电脑可用的浏览器或网页工具采集；需要登录时沿用正常登录，不绕过付费或验证码。必须实际查看图片，不能用搜索缩略图冒充已核对结果。

每批保留独立 collection.json、来源证据和图片。附带 Python 3 脚本只生成 `.hzlib`，不写数据库；Codex 可使用自己的可用 Python，无需为主软件安装开发环境。字体裁图工具额外需要 Pillow；如果缺失由 Codex 使用可用图像工具或安装到独立环境，不修改软件运行库。

在软件对应库点“导入”，选择生成的 .hzlib，核对预览和目标分组后追加。Codex 有实际窗口工具时可自动完成，也可按 Skill 的本机 API 协议操作。不要误点“导入图片/智能整理”，这些功能可能调用计费模型。.hzlib 导入不调用 AI。

成功结果应包含：实际新增/跳过/冲突数量，分类与搜索入口，来源清单和共享包，桌面图片与备注的验证结果。重复包自动跳过；冲突先核对，保留已有内容。不清空库、不重置 API。若 Codex 无网页/图片/桌面工具，应如实交付已完成资料，不能声称已核对或入库。

## 把整理好的内容分享给别人

Skill 包是采集能力，不包含现成库。分享现成内容时，在提示词库或字体库选择授权分享的条目/分组，点“导出”生成 .hzlib；同事在对应库“导入”。不要发送整个用户数据目录，里面可能含 API、私人项目和账号信息。保留原作者署名与使用限制，采集参考不等于获得商业授权。
