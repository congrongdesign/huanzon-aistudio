## 已交付

- 模型配置改为双栏：服务列表与模型列表；主页面移除能力路由、激活管理、常驻配置抽屉和筛选侧栏。
- 新增和编辑统一使用居中弹窗，提供 API 地址、密钥与可选名称；接口类型按地址自动适配。

- 连接操作使用独立请求和超时机制；原有与新配置写入共用串行队列，避免旧请求覆盖新保存。
- 草稿关闭前提供放弃确认；检测不会切换画布正在使用的模型。
- 去背景专用服务设置移到选中图片的工具栏设置按钮；原有专用路由数据保留。
- 修正原有深色主题对激活开关的覆盖，开、关状态具有明显对比。
