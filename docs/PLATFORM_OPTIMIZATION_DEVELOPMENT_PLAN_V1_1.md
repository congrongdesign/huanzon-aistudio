# 平台优化开发计划（v1.1 整合版）

日期：2026-06-15  
范围：环中 AIStudio 主平台优化  
说明：转换中心已有独立 PRD，本计划不重复展开；多模型对比不纳入范围。

## 1. 目标

把当前平台从“功能多、入口散、视觉不统一”收敛为“视觉统一、核心流程稳定、资产可复用、提示词可回流、后续易维护”的生产型工具。

## 2. 已完成 / 已确认方向

1. 深色模式的大方向已确认：黑白灰主导，去掉发光感，减少蓝色偏置。
2. 统一控件底座已经开始收敛，后续新增页面应直接复用统一样式。
3. 低价值入口已明确要继续收敛，包括 agent 中心、访客模式、飞书云同步等。
4. PPT 工作台、批量模块、资产库、图库、画布之间的边界已经明确，后续不再各自重复造入口。
5. 转换中心暂缓主线优化，先把平台本体体验做稳。

## 3. 当前问题

1. 深色模式仍有蓝色残留，按钮、下拉框、选中态、hover、边框、弹窗、背景还不够统一。
2. 浅色模式也有部分比例、字号、留白、边框识别性不一致的问题。
3. 归档图库、回收站、作品库、画布之间的链路还不够顺，部分操作存在耦合。
4. 画布里的局部重绘、智能选区、提示词回流、参考图缩略图展示仍可优化。
5. 资产库、提示词库、PPT 工作台、批量模块之间联动不够顺滑。
6. `page.tsx`、`PPTWorkshop.tsx`、`PromptManager.tsx` 等大文件继续堆补丁，会越来越难维护。

## 4. 优化原则

1. 先统一，再扩展。
2. 先减法，再加法。
3. 先稳定主流程，再做增强功能。
4. 所有新增功能必须接入统一的视觉、状态、历史、错误体系。
5. 不围绕低价值模块继续堆功能。

## 5. 分阶段计划

| 阶段 | 目标 | 核心任务 | 结果 |
|---|---|---|---|
| P0 | 基线收敛 | 统一视觉 token、收敛入口、清理残留文案 | 后续开发有统一规则 |
| P1 | 全站 UI 统一 | 深浅色统一、按钮/下拉框/弹窗/边框统一 | 视觉一致、无明显蓝色残留 |
| P2 | 功能减法 | 移除低价值入口、合并重复模块 | 主流程更短、更清晰 |
| P3 | 画布底座 | 智能选区、局部重绘、历史回退、提示词回流 | 画布可稳定编辑 |
| P4 | 资产系统 | 图库、参考库、灵感库、归档、回收站、标签、检索 | 资产可复用、可追踪 |
| P5 | 工作台优化 | PPT 工作台、批量模块、任务状态、导出流程 | 生产效率更高 |
| P6 | 提示词收口 | 提示词库、模板、版本、回流、来源关联 | 提示词能反哺创作 |
| P7 | 结构重构 | 拆分大文件、抽公共组件、收口 feature module | 后续维护更顺畅 |

## 6. P0 基线收敛

1. 统一全站基础视觉规则。
2. 确定保留、收敛、删除的入口清单。
3. 明确颜色使用边界，避免后续再次引入蓝色偏置。
4. 固化按钮、下拉框、标签、弹窗、hover、focus、disabled 的统一规范。

## 7. P1 全站 UI 统一

1. 深色模式再压深一点，提升层级对比，减少发灰发脏。
2. 浅色模式同步修正按钮大小、选中态、边框、下拉框高度、字体比例。
3. 统一背景、卡片、浮层、输入框、按钮、图标、边框、阴影。
4. 去掉蓝色高亮残留，统一成黑白灰体系。
5. 所有模块统一检查：
   - 画布
   - 项目栏
   - 图库
   - 资产库
   - 提示词面板
   - PPT 工作台
   - 批量模块
   - 弹窗和下拉框

## 8. P2 功能减法

1. 继续移除或隐藏不再需要的入口。
2. 合并重叠功能，减少同一动作在多个地方出现。
3. 收敛侧栏、顶部栏、二级面板里的重复动作。
4. 保留本地与 NAS 这类真正高频的工作路径。
5. 不再继续维护低价值、低频、使用场景不明确的独立模式。

## 9. P3 画布底座

1. 智能选区更像“可直接点中小元素”的工具，而不是粗糙框选。
2. 鼠标悬停时能识别元素层级，并给出透明覆盖预览。
3. 框选、补涂、蚂蚁线、预览层、提交层保持一致。
4. 局部重绘保留历史，可撤回、可恢复、可复用。
5. 画布里的图片支持直接读取提示词，并一键回流到提示词库。
6. 发送消息里的参考图统一用缩略图展示，不再让文字跑版。

## 10. P4 资产系统

1. 图库、参考库、灵感库、归档图库、回收站统一浏览逻辑。
2. 归档图库与回收站彻底解耦，不能再共用同一份文件生命周期。
3. 作品库到归档要有明确交互入口，不能只依赖画布右键。
4. 归档、新建文件夹、恢复、永久删除、清空回收站都要可直接操作。
5. 资产库要支持：
   - 标签
   - 搜索
   - 项目归属
   - 提示词回流
   - 直接回填画布

## 11. P5 工作台优化

1. PPT 工作台、批量模块的视觉风格统一。
2. 批量模块与工作台如果能力重叠，优先合并成一个更清晰的入口。
3. 任务状态、失败原因、重试、删除、导出等操作要清楚。
4. 预览卡片要更克制，减少横向长卡片和过多信息堆叠。

## 12. P6 提示词收口

1. 从画布图片读取提示词，并一键加入提示词库。
2. 提示词库保留分类、模板、版本、测试、快速插入等核心能力。
3. 统一提示词来源关联，能回查原图、项目、模型、比例、时间。
4. 减少重复管理入口，让提示词能自然回流到画布和工作台。

## 13. P7 代码结构重构

1. 拆分 `src/app/page.tsx` 的高耦合逻辑。
2. 拆分 `PPTWorkshop.tsx`、`PromptManager.tsx`、`BatchModule.tsx`、`AssetCollectionsPanel.tsx` 的复杂区域。
3. 把统一主题、统一按钮、统一下拉框、统一弹窗抽到公共层。
4. 降低后续每次修改都要“到处补洞”的成本。

## 14. 不做范围

1. 转换中心不纳入本轮主线。
2. 多模型对比不开发。
3. 不再继续给低价值入口加复杂交互。
4. 不把局部问题继续用补丁堆叠方式解决。

## 15. 验收标准

1. 深色模式没有明显蓝色残留。
2. 浅色模式与深色模式在按钮、下拉框、边框、弹窗、背景上统一。
3. 归档图库和回收站彻底分离。
4. 画布的选区、重绘、提示词回流能稳定工作。
5. 资产库、提示词库、PPT 工作台之间的跳转更短、更顺。
6. 主导航更少、更清晰，低价值入口明显减少。
7. 后续改动不再依赖在超大文件里反复打补丁。

## 16. 推荐执行顺序

1. 先完成 P0 和 P1，彻底把视觉和基础交互统一。
2. 再做 P2，收敛入口和重复模块。
3. 然后做 P3，补强画布底座。
4. 接着做 P4，修资产体系和归档/回收站。
5. 再做 P5，稳定工作台和批量能力。
6. 最后做 P6 和 P7，完成提示词收口与代码重构。

## 17. 结论

本轮优化不应该继续靠局部补丁堆砌，而是先统一规则，再清理入口，再补强核心流程。平台真正需要的是稳定、可复用、可维护的主链路，不是更多相似功能。
