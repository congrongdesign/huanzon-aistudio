# Agent 与 PPT 风格确认使用说明

## 1. 画布里的对话模式和设计 Agent 模式

画布右侧对话框现在有两种模式，可以在对话框顶部切换：

### 对话模式

位置：右侧对话面板顶部选择 `对话模式`。

适合：
- 问一句话
- 直接生成一张图
- 优化提示词
- 引用画布图片继续生成
- 使用提示词库和自定义技能

说明：对话模式更像普通 AI 聊天和简单生图。

### Agent 模式

位置：右侧对话面板顶部选择 `Agent模式`，或点击顶部快捷按钮 `Agent模式` 自动打开右侧面板。

这是平台里的“设计执行 Agent”，不是代码开发 Agent。

适合：
- 帮你拆解设计任务
- 基于参考图出多个设计方向
- 基于画布已有图片做延展、改版、系列化
- 自动生成多张方案并放到画布
- 帮你把模糊需求变成可执行的生图任务

工作方式：
- 它会读取当前画布图片的提示词、比例、模型等上下文。
- 你上传或引用参考图后，它会把参考图用于设计方案。
- 需要出图时，它会调用平台已有生图模型，不会修改平台代码。
- 生成完成后，图片会自动出现在画布上。

## 2. PPT 工作台里的 Agent 如何调用

PPT 工作台的 Agent 是流程型能力，不是单独聊天按钮：

1. 上传 PPT / 图片包。
2. 系统显示任务拆解流程。
3. 在风格确认阶段填写 Brief。
4. 每个风格方案单独填写风格要求、单独设置参考图。
5. 点击生成风格方案。
6. 确认一个风格后，进入自动美化。
7. 自动美化完成后进入审核，每个方案会显示自动评审。

也就是说，PPT 工作台里的 Agent 会跟随工作流程自动运行；画布右侧的 Agent 模式则用于临时布置设计任务。

## 3. 风格确认规则

已经取消：
- 全局参考图
- 全局风格预设
- 所有方案共用同一套参考图

现在规则：
- 每个风格方案都是独立卡片。
- 每个方案可以单独填写风格定位。
- 每个方案可以单独上传参考图。
- 每个方案可以从 NAS 单独选择参考图。
- 可以点击 `+ 增加一个独立风格方案` 手动增加方案。
- 不满意可以单独重生某个方案。

## 4. 工具配置简化

API 配置里新增：
- `一键使用推荐国内节点`
- `一键复用生图 API 配置`

左侧 `Agent` 页面用于检测本机和平台相关能力：
- Ollama
- ComfyUI
- LibreOffice
- Poppler
- NAS / 本地资产路径
- 飞书知识库

检测页只负责显示工具是否可用，不会自动修改电脑配置。
