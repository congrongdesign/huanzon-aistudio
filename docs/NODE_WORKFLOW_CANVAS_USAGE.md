# 节点画布使用说明

日期：2026-06-01

## 功能说明

本次已把节点画布融入到环中AIStudio 主画布中。它不是替换原来的图片画布，而是在原画布上增加一层“节点模式”，必要时也可以切换成独立节点画布，避免和原图片画布的拖拽、框选操作互相干扰。

节点模式可以把这些东西连起来：

1. 资料节点：项目背景、产品信息、设计要求。
2. 参考图节点：来自画布图片、本地/NAS/飞书导入图片或手动 URL。
3. 提示词节点：可复用的生图提示词。
4. 生图任务节点：读取上游资料、提示词、参考图，并调用当前配置的生图模型。
5. 结果节点：生成完成后自动形成结果节点，记录和任务的关系。

## 如何打开

1. 打开主画布。
2. 顶部工具栏点击“节点”。
3. 画布上会出现节点工具条和右侧节点检查器。

## 基本操作

### 模式选择

节点工具条左侧有“叠加模式 / 独立模式”切换：

1. 独立模式：默认模式，节点画布独占鼠标操作，适合大量拖拽节点、拖线、梳理流程。
2. 叠加模式：节点浮在原图片画布上，适合把已有图片转成参考节点。

如果感觉节点拖动影响原画布，切到“独立模式”即可。

### 创建节点

在节点工具条中点击：

1. “资料”：创建项目资料节点。
2. “提示词”：创建提示词节点。
3. “生图任务”：创建可以执行的生成节点。
4. “选中图转节点”：先在画布中选中一张或多张图片，再点击这个按钮，图片会变成参考图节点。

### 连接节点

1. 按住一个节点右侧的“+”圆点或右侧边缘热区。
2. 拖出连线，移动到目标节点上。
3. 目标节点高亮后松开鼠标，即可完成连接。
4. 也可以先点击源节点右侧“+”，再点击目标节点左侧“in”。
5. 连线中间的“x”可以删除连线。

建议连接方式：

1. 参考图节点 -> 生图任务节点。
2. 提示词节点 -> 生图任务节点。
3. 资料节点 -> 生图任务节点。
4. 生图任务节点执行后，会自动连接到结果节点。

### 执行生图任务

1. 先创建或选择一个“生图任务”节点。
2. 在右侧节点检查器里填写生成要求。
3. 把参考图节点、提示词节点、资料节点连接到它。
4. 点击“执行这个节点”。
5. 生成结果会同时出现在原画布里，并在节点画布中生成一个“结果节点”。

### 把画布图片接入任务

方式一：

1. 在原画布选中图片。
2. 打开节点模式。
3. 点击“选中图转节点”，图片会变成参考图节点。
4. 从参考图节点拖线到生图任务节点。

方式二：

1. 选择一个“生图任务”节点。
2. 展开右侧节点面板。
3. 在“连接画布图片”里点击图片缩略图。
4. 系统会自动创建参考图节点，并连接到当前任务节点。

## 保存机制

节点数据先保存在当前项目的本地缓存里，不需要新建数据库表。

也就是说：

1. 同一台电脑、同一个项目，再次打开仍然能看到节点。
2. 换电脑不会自动同步节点。
3. 后续如果需要团队协作，可以升级为数据库保存。

## 当前版本边界

已完成：

1. 节点创建、拖拽、编辑。
2. 节点连线和删除连线。
3. 选中画布图片转参考图节点。
4. 生图任务节点调用当前生图模型。
5. 生成完成后自动创建结果节点。
6. 节点数据按项目本地保存。

暂未做成重型后端队列：

1. 多用户同步。
2. Redis/PostgreSQL 队列。
3. 服务端任务恢复。
4. 节点模板库。
