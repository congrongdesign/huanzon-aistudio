# Skill 库使用说明

## 现在已经接入的 Skill

已接入：`图片转可编辑 PPT`

来源：`ningzimu/image-to-editable-ppt-skill`

用途：把幻灯片截图、图片包、PDF、图片版 PPT/PPTX 尽量重建成对象级可编辑的 PowerPoint 文件。它会优先把可读文字恢复成 PPT 文本框，把简单形状恢复成 PPT 形状，复杂视觉元素会作为独立图片资产放入 PPT。

## 使用前准备

1. 确认本机已经安装 Codex。
2. 确认 Codex 已登录，可以正常运行本地任务。
3. 已安装本 Skill：`/Users/congrong/.codex/skills/image-to-editable-ppt/SKILL.md`。
4. 平台需要用本地模式或已登录模式打开。

## 在平台里怎么用

1. 打开平台：`http://127.0.0.1:3100/`
2. 进入任意项目。
3. 打开右侧对话区上方的 Skill 按钮。
4. 切到 `Skill 库`。
5. 找到 `图片转可编辑 PPT` 卡片。
6. 选择一种运行方式：
   - `用选中图片运行`：先在画布里选中一张或多张幻灯片图片，再点击按钮。
   - `上传文件运行`：直接选择图片、PDF、PPT/PPTX 或 ZIP 图片包，再点击按钮。
7. 切到 `任务` 标签页，查看运行状态。
8. 任务完成后，在输出文件列表里下载 `.pptx`、预览图和校验报告。

## 安装到当前项目

在 Skill 卡片里点击 `安装到当前项目`，它会出现在 `我的` 标签页里。以后可以像普通技能一样点击运行。

## 输出在哪里

平台任务文件会保存在：

`/Users/congrong/Documents/AI平台/output/skill-runs/`

每次运行会创建一个独立任务文件夹，通常包含：

- `input/`：本次输入文件
- `final/`：最终 PPTX 和报告
- `run.log`：运行日志
- `run.json`：任务状态

## 常见问题

### 任务一直失败

优先检查 `任务` 里的错误提示。如果还不清楚，打开对应任务的 `run.log`。

### 提示 Codex skill 未安装

检查这个文件是否存在：

`/Users/congrong/.codex/skills/image-to-editable-ppt/SKILL.md`

如果不存在，需要重新安装该 Skill。

### 生成很慢

这是正常情况。这个 Skill 是对象级重建，不是简单把图片塞进 PPT。页数越多、页面越复杂，耗时越长。

### 转出来不是 100% 一样

这是当前能力边界。它追求“可编辑率”，不是单纯截图级复刻。复杂图表、复杂背景、特殊字体可能需要人工复核和微调。
