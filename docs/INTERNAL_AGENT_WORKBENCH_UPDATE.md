# 内部 Agent 工作台更新说明

更新时间：2026-05-31

## 已完成

### 1. 本地能力检测

新增接口：`/api/local-capabilities`

可检测：
- Codex CLI（可选开发维护工具）
- Claude Code
- Gemini CLI
- Qwen CLI
- Ollama
- ComfyUI
- LibreOffice
- Poppler
- Node.js
- pnpm
- NAS / 本地资产路径
- 飞书知识库配置

检测结果不会修改电脑配置，只用于显示“可用 / 需处理 / 未配置”。

### 2. Agent 中心与右侧设计 Agent

新增左侧导航入口：`Agent`，用于检测本机能力和进入相关工作区。

右侧对话框新增 `对话模式 / Agent模式` 切换。`Agent模式` 是平台内的设计执行 Agent，会调用对话模型、生图模型、参考图和画布上下文来完成设计任务。

Agent 中心会显示：
- Ollama、ComfyUI、LibreOffice、Poppler 等工具是否可用
- NAS / 本地资产路径是否可访问
- 飞书知识库配置是否完整
- 缺什么以及下一步怎么处理
- 一键进入对应工作区

### 3. PPT 工作台 Agent 化

新增：
- Agent 任务拆解面板
- 结构化 Brief
- 风格预设库
- 风格确认阶段的预设注入
- 批量美化任务恢复提示
- 方案自动评审卡

Brief 字段：
- 使用场景
- 目标受众
- 参考来源
- 交付格式
- 必须保留
- 禁止事项

风格预设：
- 科技发布会
- 高端商务
- 国风文化
- 教育培训
- 品牌提案
- 极简高级

### 4. 自动评审基础版

每个生成方案会生成规则评审：
- 文字完整
- 风格一致
- 排版层级
- 图片清晰
- 风险等级
- 简短建议

当前为规则评审 + 已有文字校验结果，不额外消耗模型调用。后续可升级成模型评审。

### 5. 任务恢复基础版

如果刷新页面导致批量生成中断，重新打开 PPT 工作台时会提示：
- 有多少页或方案未完成
- 可以继续生成
- 可以重置状态

说明：浏览器请求已经断开时，无法恢复同一个网络请求；当前策略是保留已完成结果，把未完成项重新排队。

## 风险控制

1. 没有改数据库结构。
2. 没有删除旧功能。
3. 旧 PPT 项目会自动迁移新增字段。
4. 本地检测失败只显示未检测到，不影响主应用。
5. Agent 中心只做检测、引导和工作流入口；右侧 `Agent模式` 负责执行平台内设计任务，不负责修改代码。
