# 画布离屏空白与整理修复

## 已确认原因

2026-11-15 在 `/Applications/环中AIStudio.app` 的实际窗口复现：按空格拖动画布到远处，DOM 图片节点降至 0；右键“整理画布”后仍为 0，transform 不变。菜单直接调用 `autoArrangeCanvas`，遗漏已有 `arrangeCanvasAndFit`，因此整理位置不会恢复视角，布局未变化时也一样。

诊断时项目含 8 张作品、3 张参考图，坐标尺寸正常，抽查原图与缩略图均 HTTP 200。重启后全部可显示。首次故障的完整时序无法事后还原，不能断言所有空白均由离屏造成。

## 修改

- 右键和顶部整理共用“排列并适应视野”；无需移动图片时同样恢复视角。
- 顶部增加“适应全部”，仅调整相机；实际视野没有内容时显示图片数量和“找回图片”。离屏判断与带预加载边界的渲染裁剪分开计算。
- 使用稳定 callback ref 追踪真实画布节点挂载与替换，立即测量尺寸并连接 ResizeObserver；进入画布、项目加载完成时重新适应内容。
- 尚未获得有效视口时暂缓裁剪，避免把未知尺寸误判成所有图片都不该显示。无效几何仍隔离。
- 保留现有拖动的低频视口更新，不引入逐帧 React 渲染。
