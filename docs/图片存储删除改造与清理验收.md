# 图片存储、删除改造与清理验收

日期：2026-11-15。本机当前安装应用已更新，源码同步。

## 已实现

- 本机媒体统一检查画布、参考图、回收站、字体作品、收藏、草稿及其他 JSON 资产引用。历史生成日志、备份目录索引不再永久占有原图；未知索引仍保守保留，损坏索引停止清理。
- 先保存业务删除，再持久化处理物理文件清理任务。共享资源保留；按文件指纹删除所有已登记位置的相同副本，失败可重试。生成和备份期间暂停。
- 新删除画布和字体作品保留 30 天，应用运行时维护到期删除。旧删除记录不追溯设定过期时间，历史清理由用户明确授权后执行。
- NAS 备份校验完成后才移出项目；验证包和本地字节，保留共用资源。备份本身不因本机清理而删除。
- 删除/移出项目后，其浏览器草稿、参考图布局不再保留历史图片。独立收藏、其他仍存在项目及字体草稿继续保留。
- 已不存在作品的历史字体生成配方不再永久保留输入图片。
- 修复 Electron 每次启动合并旧 `projects` 数据目录导致已删文件复活的问题。已有主数据库视为权威数据；旧版迁移只执行一次。
- 储存页面区分画布、字体、其他素材、回收站及未引用空间；扫描包含已删除字体作品。缺失检查包括参考图及其他登记素材。

- TypeScript、Electron 编译、生产构建及目标 ESLint 通过。

- 云端 S3 删除分支未在本次重构和实机验证；没有完成完整内容寻址存储或 SQLite 迁移。自动维护不是系统常驻计划任务，应用关闭时不执行。
