# 案例中心参考图库改造

## 交付范围
跨项目参考图库、单图/多图/ZIP 导入、分类（多分类归属）、标签与批量整理、搜索/比例/标签筛选、收藏、最近使用、分页、缩略图大小、详情编辑与大图预览、回收站恢复、图库原图及资料 ZIP 备份导入、输入工具中直接选图引用、添加到画布。移除旧 PPT 案例面板及入口；旧案例图片按条目迁入，成功记录迁移 ID，失败保留来源并提示重试。旧浏览器记录仅保留作迁移来源，不再展示旧界面。

## 设计
沿用现有 shadcn / Tailwind / Lucide 和深浅主题变量；左分类、中图片、右详情。无营销式装饰，主操作围绕收集、整理和引用。缩略图按需生成，原始图片字节保留，48 张分页。原图哈希去重，分类独立关联；元数据按用户保存在 local-data/case-library/ 下，原图使用现有媒体存储目录与迁移机制。索引原子写入及文件锁保护并发。储存清理引用扫描显式保留图库和回收站原图。

## 验收清单
- 单图及多图上传、相同文件重复上传、损坏文件；ZIP 资料备份往返。
- 分类创建/改名/移除，图片多分类，批量标签、收藏切换、搜索及清空、比例筛选、排序、缩略图大小。
- 多选、Shift 连选、全选/取消，详情保存、大图打开关闭、软删除及恢复。
- 图库选中加入参考，输入框选图入口，保留原草稿及参考，模型数量上限，添加到画布后重载保留。
- 旧案例迁移可重入、跨项目同库、千图分页、损坏索引保护、原图 GC 引用保护。
- 浅色/深色、1440×900 与较小窗口；空态、加载、无匹配、失败提示。
- pnpm ts-check、变更文件 lint、生产构建及存储脚本测试。
- 更新安装版、确认运行目录和 BUILD_ID、实际窗口验证、清除临时测试运行目录。

## 边界
本轮不调用付费模型，不提供自动视觉打标、颜色识别、语义搜索或以图搜图。分类为扁平多归属分类，可后续增加层级。回收站暂不提供永久删除，以避免破坏项目引用。图库 ZIP 独立备份，不声称原有按项目备份已包含整个全局图库。
