# 画板功能优化评估与落地清单（2026-06-24）

## 1. 目标与范围

本次文档用于沉淀当前「画板」能力的完成度评估、已实现项、剩余风险以及后续优化顺序。范围覆盖：

1. 画板拖拽/缩放/整理体验  
2. 画板内图片的批量拖入、自动整理、拖出  
3. 画布整理与画板整理之间的边界  
4. 深色模式可见性  
5. 对话模式 / 直接生图模式协作  
6. 失败图片清理能力

---

## 2. 当前已完成能力（对照用户历史诉求）

### 2.1 交互与功能

1. 支持对话输入区「对话模式 / 直接生图」切换，支持持久化模式状态。  
2. 直接生图模式下，不再依赖意图识别，按提示词直接走生图流程。  
3. 画布右键菜单支持「清除失败图片」。  
4. 支持新建画板、重命名画板、锁定/解锁、删除画板。  
5. 支持图片拖入画板、画板内自动整理、图片移出画板。  
6. 支持多选图片拖拽（含批量拖入画板）。  
7. 支持选中画板后 `Ctrl/⌘ + 滚轮` 缩放画板内图片。  
8. 支持按住空格键在选中画板状态下自由拖动画板（不必严格抓顶部栏）。  
9. 画板缩放手柄命中区已放大，缩放操作可控性提升。  
10. 已移除画板周边图片自动避让导致的全局“乱跳”策略（保留画板内整理）。

### 2.2 稳定性

1. 图片 natural size 加载阶段已改为仅缓存尺寸，不再触发隐式重排。  
2. 切项目、切页返回导致画布散开的核心路径已降低触发概率。  
3. 画板内缩放步进与滚轮灵敏度已下调，避免“一次滚轮变化过大”。  
4. 画板缩放手势已补充历史快照，撤销/重做可回到缩放前状态。

### 2.3 视觉

1. 画板深色模式背景已降低遮罩强度，取消 blur，减少“蒙版感”。  
2. 画板内图片在未选中态增强边界可见性，降低“看不到图”的问题。

## 3. 本轮新增修复（2026-06-24）

1. 统一默认文案：后端默认名称从「区块」调整为「画板」。  
   - `src/app/api/canvas-blocks/route.ts`
   - `src/app/api/canvas-blocks/[id]/route.ts`
   - `src/lib/local-backend.ts`
   - `src/storage/database/shared/schema.ts`

2. 画板缩放撤销链路修复：  
   - 缩放手势开始时记录画布图片快照；  
   - 手势结束时将快照推入撤销栈；  
   - 避免“缩放后撤销无法回退到缩放前布局”。

3. 失败图片清理范围补全：  
   - 将 `upload-*` 占位失败项纳入“一键清除失败图片”。

## 4. 仍需关注的风险点

1. **超大画布数据量（>1000 图）性能风险**  
   - 主要在多次 map/reflow、批量 PATCH、快速拖拽时出现卡顿。  
2. **自动整理触发时机的一致性**  
   - 目前以显式触发 + 拖入触发为主，仍需持续避免隐式重排回归。  
3. **复杂批量操作的撤销粒度**  
   - 现在已覆盖核心路径，但极端并发操作（拖拽 + 缩放 + 批量处理）仍需回归。  
4. **画板视觉层级可读性**  
   - 已改善，但若后续增加更多层级元素（注释、分组标记），需引入更严格层级规范。

---

## 5. 下一阶段优化建议（按优先级）

### P0（稳定性）

1. 为画板相关变更补最小化回归脚本（拖入、整理、缩放、撤销重做）。  
2. 将批量位置持久化请求做节流与分帧，降低卡顿和请求风暴。  

### P1（体验）

1. 增加画板「排序模式」快速切换（紧凑/按时间/按批次）可视开关。  
2. 增加画板内“仅看选中批次/仅看来源链路”筛选。  

### P2（可维护性）

1. 把 `page.tsx` 中画板逻辑拆为 hooks（layout/history/interaction）。  
2. 为画板状态引入更清晰的数据边界（画布自由图 vs 画板内图）。

---

## 6. 验收建议（手测清单）

1. 多选 5~20 张图拖入画板，确认自动整理顺序稳定。  
2. 选中画板后 `Ctrl/⌘ + 滚轮` 连续缩放，再执行撤销/重做。  
3. 切到其他项目再切回，确认画板与图片位置稳定。  
4. 深色模式下确认画板内图片可见、无遮挡蒙版。  
5. 右键「清除失败图片」，验证画布与图库失败项均能清理。
