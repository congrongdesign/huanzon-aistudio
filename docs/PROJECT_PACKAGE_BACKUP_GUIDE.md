# 项目画板导入导出与备份说明

## 项目包是什么

项目包是 `.hzproj.zip` 文件，用于保存一个完整项目画板。

包含内容：
- 项目名称和基础信息
- 画布上的图片记录、位置、尺寸、模型、提示词
- 对话记录和引用图片记录
- 参考图
- 提示词库内容
- 项目内技能
- 图片资源文件

## 导出项目

1. 打开左侧“项目画板”。
2. 鼠标移动到某个项目名称上。
3. 点击项目右侧的下载图标。
4. 系统会下载一个 `.hzproj.zip` 项目包。

这个文件可以发给同事，也可以放到 NAS、移动硬盘或云盘里保存。

## 导入项目

1. 打开左侧“项目画板”。
2. 点击顶部的上传图标。
3. 选择之前导出的 `.hzproj.zip` 文件。
4. 系统会创建一个新的“导入”项目，不会覆盖原有项目。

注意：当前导入恢复优先支持本地模式。在线数据库模式暂不直接写入，避免误覆盖云端数据。

## 备份到 NAS / 本地目录

1. 先在系统里把 NAS 挂载成磁盘目录。
2. 鼠标移动到项目名称上。
3. 点击云朵上传图标。
4. 在弹窗里填写备份目录。
5. 点击“备份到目录”。

macOS 示例：
`/Volumes/你的NAS/AIStudio备份`

Windows 示例：
`Z:\AIStudio备份`

系统会把项目包直接写入这个目录。

## 百度网盘 / 飞书知识库

这两个目标不能只靠一个路径完成自动上传，需要开放平台授权：
- 百度网盘需要百度网盘开放平台 App Key、Secret 和用户授权 token。
- 飞书知识库需要飞书开放平台 App ID、App Secret、知识库空间权限。

当前界面已预留入口，但不会做假上传。后续接入授权后，可以把同一个项目包自动上传到对应平台。

## 建议使用方式

- 每个重要项目完成后导出一次项目包。
- NAS 备份目录建议按月份分文件夹。
- 发给同事时，直接发送 `.hzproj.zip`，对方在本地导入即可。
- 做大改动前先导出一份，方便回滚。
