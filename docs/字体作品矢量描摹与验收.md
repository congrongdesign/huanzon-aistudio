# 字体作品 → Illustrator 矢量描摹

入口：字体创作的作品卡片曲线图标、更多菜单，以及作品详情中的「矢量描摹」。可选择黑白字稿或最多 16 色的彩色图稿；黑白可设置阈值和去白底。生成图片不经过付费模型，直接读取原图。

## 桌面集成

- macOS 通过 `com.adobe.illustrator` 应用标识和 AppleScript 的 `do javascript` 调用已安装版本，不依赖 2026 的路径。系统可能要求自动化、下载目录或网络宗卷权限，需要用户在系统提示中允许。
- Windows 使用 PowerShell 调用 Illustrator COM：优先复用 `Illustrator.Application` 的运行实例，否则使用通用 ProgID 启动，失败时从注册表枚举已注册版本，按版本号倒序尝试。没有写死安装盘符、年份或界面语言；Illustrator 必须正确注册 COM 接口。
- macOS / Windows 共用 ExtendScript：新建文档 → 嵌入原图供对照 → 独立图层图像描摹 → 展开为路径 → 保存 `.ai` 并保持打开。字体轮廓可编辑，不能直接键入替换文字。
- 输出到设置中的下载目录（未设置时使用系统下载目录），文件名附随机标识避免覆盖。临时图片和脚本在任务结束后清理。
- 原图读取兼容当前储存目录、旧媒体目录与局域网客户端；字体原图路径为 `font-library/files`。下载/描摹忽略缩略图参数。
- 全局一次执行一个任务。错误区分旧桌面组件未加载、浏览器环境、未安装/COM 未注册、macOS 自动化未授权、Illustrator 忙及超时。超时后提示检查 Illustrator，避免声称操作已完成。

## 图像描摹面板（后续调整）

默认开启「保留描摹以便调整」：保存嵌入原图的实时描摹，选中对象并打开 Illustrator 的「图像描摹」面板。用户可调阈值、预设，满意后点「扩展」。关闭该选项仍自动展开路径。面板命令使用 `Adobe Vectorize Panel`；本机已验证面板可见且参数可操作，以及实时描摹保存重开后存在、无外部图片链接。macOS 在现有辅助功能权限可用时读取菜单勾选状态，避免已打开的面板被切换关闭；辅助功能不可用时回退到 Illustrator 自身的面板命令。保存后再确认面板勾选状态，避免保存操作恢复布局。Windows 面板与多版本行为仍待真机验证。
