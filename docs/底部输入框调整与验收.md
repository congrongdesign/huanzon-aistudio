## 验收清单（已完成）

1. 消息只显示复制和替换输入，右键菜单无收藏到字体库。
2. 空白/有内容/长文本状态：底部定位、自动长高、工具栏及菜单可见，无横向溢出。
3. 清空文字与图片后，发送禁用；切换模块、聚焦及刷新后不复活。
4. 替换输入恢复原文字和参考图；连续替换不叠加。
5. 折叠记录、调整宽度、深浅主题均不影响编辑器；选中工具栏避让输入框。
6. 模型、比例、数量及输入工具可操作；菜单往上打开且不裁剪。
7. 中文组合输入不误发；Shift+Enter 换行，Enter 发送；生成期间可以继续编辑。
8. 探索：上传中清空，迟到的上传结果不回填。
9. 探索：优化中清空，迟到的流式结果不回填；选中图片清空后再次聚焦不自动恢复。
10. 类型检查、生产构建、变更文件 lint；安装版签名、数据及实际窗口复核。

## 五项 Motif 官方组件接入

1. Cover Fan：对话批图默认显示最多四张扇形封面，悬停/键盘聚焦抬起，点击看原图；全部结果通过展开网格访问和拖拽。检查 0/1/4/8 张、未完成和窄面板。
2. Model Select：供应商索引、模型搜索、勾选和键盘选择；保留 provider::model 的实际值。大目录按段增量显示，搜索仍覆盖全部；检查同名不同来源、千条目录末项、无结果、Esc 和字体入口。
3. Resolution Picker：点阵密度、滑动选中板、真实参数值。像素模式显示实际尺寸，Nano 与字体显示 K 档位；检查切模型后的可用值与提交请求。
4. Generation Overlay：官方蓝紫流动光、排队/运行/重连状态与取消；解码完成后淡入清晰结果，失败可重试。检查并发、完成、图片预览回退、减少动态、历史缓存图。
5. Flow Edge：同一项目来源图片/参考图到结果的连接，任务中流光、完成后静态线；拖拽/缩放/画板缩放同步，离屏不挂载。关系由原有 reference_images 恢复，兼容旧图片 ID 格式；扩图、局部重绘、AI 编辑和图片工具补齐来源与过渡身份。

功能与视觉均须检查：深浅主题、1280×800、窄窗、实际安装窗口。异常探索：搜索无结果后点击供应商、未完成批图点击已完成图、生成中清空并下载历史图、删除来源/跨项目引用不乱连。使用隔离数据及模拟生成，不提交付费生图。
