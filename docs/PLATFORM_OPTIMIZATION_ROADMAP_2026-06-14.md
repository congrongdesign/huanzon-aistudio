# 平台优化路线图

版本：v1.0  
日期：2026-06-14  
范围：环中AIStudio 主平台优化，不包含转换中心

---

## 1. 目标

把当前平台从“功能较多但体验割裂”收敛成“界面统一、核心流程稳定、资产可复用、编辑可回退”的生产型工具。

---

## 2. 总原则

1. 先统一，再扩展。
2. 先减法，再加法。
3. 先稳定主流程，再补充新能力。
4. 所有新功能必须接入统一的视觉、状态和历史体系。

---

## 3. 当前优先问题

1. 深色模式和浅色模式不统一，蓝色残留多，选中态、hover、边框、下拉框、弹窗风格混乱。
2. 主入口模块过多，重复功能和低价值入口影响使用效率。
3. 画布编辑链路还不够稳定，局部重绘、选区、回退、预览一致性仍需加强。
4. 资产库已经能用，但还不够“可复用”和“可检索”。
5. PPT 工作台可用，但还可以更稳、更快、更少打断。
6. 主入口代码过大，后续继续修 UI 和功能会越来越难维护。

---

## 4. 优先级路线

### P0：全站 UI 统一

目标：先把“看起来像不同产品”的问题解决掉。

要做的事：

1. 清理全站蓝色/紫色残留，统一成黑白灰体系。
2. 统一按钮、下拉框、输入框、弹窗、悬停、选中态、边框、阴影。
3. 修复深色模式下的字体可读性、图标可见性、底色穿透问题。
4. 把高频组件做成统一样式，避免每个模块各写一套。

验收标准：

1. 深色模式不再出现明显蓝色 UI 残留。
2. 同类控件在各模块中视觉一致。
3. 下拉框、按钮、选中态在浅色和深色下都清晰可读。

---

### P0：功能减法与入口收敛

目标：减少干扰，让用户更快进入核心任务。

建议处理：

1. 继续移除或隐藏低频模块。
2. 收敛重复入口，保留一个主入口，其他入口降级到二级位置。
3. 去掉使用场景不明确的独立模式和面板。
4. 把高频动作放回主流程，不要拆得太散。

重点方向：

1. 继续压缩主导航。
2. 合并重复的工作台功能。
3. 让资产、提示词、PPT、画布之间跳转更直接。

---

### P1：画布编辑底座

目标：把“可选、可涂、可改、可回退”做稳定。

要做的事：

1. 智能选区继续优化，确保点击、框选、补涂都能稳定工作。
2. 局部重绘结果和预览保持一致。
3. 撤回、重做、历史记录统一管理。
4. 让选中态、蒙版、蚂蚁线、预览层的交互更顺。

验收标准：

1. 选区不再频繁失灵。
2. 预览和提交结果一致。
3. 回退链路可靠。

---

### P1：资产系统升级

目标：把图库从“存图”升级成“可复用资产库”。

要做的事：

1. 统一图库、参考库、灵感库的浏览和筛选方式。
2. 增加相似图、风格检索、标签自动化。
3. 支持一键回填到画布、提示词、PPT 工作台。
4. 让资产有更明确的项目归属和复用路径。

验收标准：

1. 用户能更快找到可复用素材。
2. 资产能直接进入下一步创作，不需要重复找图。
3. 不同库之间的体验统一。

---

### P1：PPT 工作台稳定化

目标：把 PPT 工作台保持成平台里的高价值生产模块。

要做的事：

1. 继续优化任务状态和刷新恢复。
2. 优化审核、重生、导出等高频动作。
3. 减少流程中的中断和等待。
4. 保持风格确认、批量美化、审核导出的一致性。

验收标准：

1. 批量任务更稳。
2. 生成结果更快可见。
3. 审核更顺，返工更少。

---

### P2：提示词与知识资产收口

目标：减少复杂度，让提示词资产真正可用。

要做的事：

1. 简化提示词管理的页面结构。
2. 保留分类、模板、版本、测试、快速插入这些核心能力。
3. 减少重复概念和层级。
4. 让提示词更方便回流到画布和工作台。

---

### P2：代码结构重构

目标：让后续优化不再靠在大文件里打补丁。

要做的事：

1. 把主入口里的大块逻辑拆成独立 feature module。
2. 抽出统一主题和通用控件规则。
3. 将高频区域的样式和交互收口到公共层。
4. 降低 `page.tsx`、`PPTWorkshop.tsx`、`PromptManager.tsx` 这类大文件的维护成本。

---

## 5. 推荐执行顺序

1. 先做 P0：UI 统一。
2. 同步做 P0：功能减法和入口收敛。
3. 再做 P1：画布编辑底座。
4. 接着做 P1：资产系统升级。
5. 然后做 P1：PPT 工作台稳定化。
6. 最后做 P2：提示词收口和代码结构重构。

---

## 6. 短期判断标准

如果后续出现以下情况，优先停下加功能，先修底层：

1. 新增模块后页面更乱。
2. UI 继续出现蓝色残留或深浅模式不一致。
3. 选区、预览、提交出现不一致。
4. PPT 或资产模块再次出现重复入口。
5. 主入口文件继续膨胀。

---

## 7. 结论

当前平台最值得投入的方向不是继续扩展模块数量，而是把已有核心能力做成统一、稳定、可维护的产品系统。
