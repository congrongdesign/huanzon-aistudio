# 生图期间下载隔离与验收

下载已有作品不应依赖生成任务是否结束。桌面版从画布悬停、选中工具栏、右键、大图预览、批量下载与整画布 ZIP 统一调用 `desktop:export-images`。预加载层通过 IPC 把导出交给主进程，文件 I/O 与生图服务独立。

本机原图按当前及历史媒体目录直接读取，忽略缩略图参数；远程图片通过主进程流式下载。导出独立限制两个任务并发，重复点击合并，ZIP 流式写入。默认保存至系统下载目录，设置过默认下载目录时沿用设置。文件先写临时文件，成功后以不覆盖已有文件的方式发布，同名自动编号；失败清理临时文件，批量返回成功与失败明细。只有实际保存完成才提示路径，下载状态不被生成提示覆盖。

专业软件参考：Adobe Illustrator 官方 [Save artwork / Save in Background](https://helpx.adobe.com/illustrator/using/saving-artwork.html) 明确说明后台保存时可继续工作；[MDN HTTP/1.x connection management](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Connection_management_in_HTTP_1.x) 解释浏览器同源并行连接通常受六连接限制。原实现仅触发同源下载链接就宣告开始，缺乏保存确认；下载仍绕经生图网页服务。新实现对桌面原图下载完全移除这两项依赖。

验证：项目与 Electron 类型检查、变更文件 Lint、Next 生产构建、`scripts/test-image-export.ts`、既有生图队列测试通过。自动化覆盖网页服务不可用、八个并发请求、重复点击、同名保护、历史媒体目录、原图字节、ZIP 内容、批量部分失败、远程错误、断流及临时文件清理。

本机 `/Applications/环中AIStudio.app` 已安装并验证：界面显示一个生成中任务时下载在 62 ms 内落盘；暂停 Next 服务后原图下载在 57 ms 内完成，SHA-256 与原图一致，无下载代理请求。右键下载、桌面批量与 ZIP 已实际落盘。并发生成使用拦截的本地模拟请求，无付费生成；原生远程供应商生成与真实断网、NAS 文件系统不作为本轮已验证项。网络故障或存储磁盘离线仍可能导致下载失败，界面会显示错误并允许重新点击。
