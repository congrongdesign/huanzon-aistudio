# NAS 连接恢复

## 实现

- macOS 通过 NetFS 原生接口挂载，后台禁止弹认证窗口，凭据由系统钥匙串管理。原生辅助程序同时包含 Apple Silicon / Intel 架构，随备份后台组件构建。
- 保存 SMB 共享地址、共享内相对目录和原仓库 ID；挂载路径发生变化时，先核验仓库 ID，再更新本机路径及未完成任务。
- 服务启动即检查；在线每 30 秒检查，离线以 5/10/20/40/80/160/300 秒退避。需要认证、权限或仓库身份错误时降低自动检查频率，用户可立即重连。窗口聚焦、网络恢复及休眠唤醒后触发检查。
- 连接检查和 NAS 扫描都在独立进程，主界面读取本机缓存；断线保留卡片，禁用备份、恢复、删除远端版本。
- 传输异常和超时进入 `waiting`，连接确认恢复后排队继续；手动暂停、取消和重启时中断的活动任务不会擅自恢复。
- 每个新备份任务先持久化操作 ID；断线重试前核对同 ID 的已提交包及内容校验，避免重复版本。发布后、本机移除前再次确认仓库和文件状态；内容发生变化时保留本机项目。
- 未完成任务不因七天历史保留规则被删除。等待中的任务可暂停、取消，仍占用同项目互斥。
- 本机额外安装登录/周期连接助手，读取应用备份配置；不创建本地目录冒充挂载点。

## 限制

当前自动 SMB 重连针对 macOS；Windows 保留系统 UNC/映射盘与已有连接检查。未做 Windows 真机认证恢复。离线任务会重新传输尚未发布的项目包，未实现单文件字节级续传。未重启用户电脑或 NAS，也未实际修改密码、断开整机网络；这些故障通过隔离场景验证，不声称已在真实设备全部演练。
