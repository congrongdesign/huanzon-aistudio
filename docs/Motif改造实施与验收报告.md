## 主要改造

| 区域 | 结果 |
| --- | --- |
| 创作输入 | 模型和生成参数放在输入区附近；比例图形选择、搜索模型菜单、附件、引用芯片、中文输入和粘贴使用同一套交互规则 |
| 对话 | Motif 消息排布和操作显隐；复制、追加文字、替换输入及参考图；向上阅读时停止自动跟随，可回到最新 |
| 等待与图片 | 真实提交、排队、运行、重连和终态；计时只在局部更新；预览解码后短淡入，预览失败回退原图；减少动态设置受支持 |
| 多任务 | 沿用持久化队列的 4 工作者、请求幂等和批量状态轮询；文字回复停止与图片任务取消各自独立，生成期间继续操作历史作品 |
| 提示词 | 保留一级分组、搜索、移动和快捷选择；新建表单按需展开，长提示词按需查看，删组保留内容 |
| 字体 | 全局作品库、独立字体会话、风格资料与个人要求分开管理；换风格替换旧配方，保留个人文字和个人参考图；保持任务提交快照、撤销及恢复机制 |
| 资产 | 完整图片、统一案例/风格详情；窄窗详情可收起。修复首次切换路径可能保存旧状态的问题 |
| 模型中心 | 来源标签与 provider::model 标识不变；表格每页 100 条，菜单最多挂载 100 项并搜索全部目录；补齐配置抽屉关闭按钮的可访问名称 |
| 设置与弹层 | 应用设置采用左分类/右内容；草稿由上层持有，分类切换和关闭重开保留；公共弹窗管理焦点返回，归档、同步、备份和资料弹层统一 |

共用组件位于 `src/components/creation`、`src/components/platform` 和 `src/components/ui/neutral-select.tsx`。Motif 的 Message、Attachment 和 StrengthSlider 基于官方 MIT 源码适配，许可说明位于 `THIRD_PARTY_NOTICES.md`，并随安装运行资源一同保留。其他组件结合现有 Radix、cmdk 和平台业务实现。

本轮没有加入新的依赖。Next standalone 补全脚本同时处理 SDK 运行依赖和 pnpm 悬空包链接，避免开发目录可运行、安装包缺文件。

生产构建 `ELECTRON_SKIP_BINARY_DOWNLOAD=1 corepack pnpm run build`、运行资源准备及 `corepack pnpm ts-check` 通过。本轮修改的页面、组件和交互工具代码 Lint 为 0 个错误。以下回归脚本全部通过：

- `scripts/test-generation-queue.ts`：并发数、幂等、用户隔离、取消、失败和服务重启。
- `scripts/test-font-creation.ts`：独立会话、换风格、个人输入、撤销、任务快照、资料收录/导出和版本冲突。
- `scripts/test-font-library.ts`：上传、权限、分组、冲突、撤销、配方引用保留、幂等和千条分页。

浅色、深色、1440 和 1280 窗口完成视觉检查。字体上传、配方保存、独立使用及替换风格，提示词一级分组，设置草稿、资产目录切换、详情收起、案例保存，以及归档/同步/备份弹窗完成界面回归。更完整的逐项记录见 `docs/Motif改造验收清单.md`。
