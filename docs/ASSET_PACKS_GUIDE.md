# 资产库项目素材包使用说明

## 这个功能解决什么问题

资产库不再只是一个全局 NAS 路径，而是按“项目”组织素材。

一个项目可以有多个素材包，例如：

- 品牌参考：绑定 NAS 上的品牌图片文件夹
- 客户 Logo：绑定本机某个本地文件夹
- PPT 原稿素材：绑定当前项目的素材目录
- 飞书知识库：绑定一个或多个飞书知识库 Space ID

切换项目后，资产库会优先显示当前项目自己的素材包。

## 傻瓜式使用步骤

### 1. 打开资产库

进入左侧工具栏的“资产库”。左侧顶部会看到“当前项目素材包”。

### 2. 新建素材包

点击“新建”，填写：

- 名称：例如“客户A品牌素材”
- 类型：选择 NAS、本地、飞书
- 路径或 Space ID：
  - NAS：填写挂载后的文件夹路径，例如 `/Volumes/DesignNAS/客户A/素材`
  - 本地：填写本机文件夹路径，例如 `/Users/你的名字/Pictures/客户A`
  - 飞书：填写 Space ID，一行一个；也可以留空使用全局飞书配置
- 说明：可选，用来记录这个素材包用途

点击“保存素材包”。

### 3. 使用素材包

点击某个素材包后：

- NAS / 本地素材包：左侧显示这个文件夹里的目录结构；点击文件夹才实时加载图片，不会一次性扫描所有图片。
- 飞书素材包：中间区域显示已同步的飞书知识库资料；如果为空，先在资产库配置里保存飞书 App ID / Secret 并刷新。

### 4. 导入素材

选择图片后可以：

- 导入参考图
- 加到画布
- 生成提示词

这些导入动作都会进入当前项目。

## 推荐组织方式

建议一个项目至少建 2 到 4 个素材包：

- 项目原始素材：客户提供的原图、Logo、产品图
- 风格参考：参考图、竞品图、视觉方向图
- 输出素材：确认后的图、可复用图
- 飞书资料：项目需求文档、品牌规范、团队资料

## 注意事项

- 删除素材包只删除“映射关系”，不会删除 NAS、本地或飞书里的原文件。
- NAS 路径必须先在系统里能打开；如果系统访问不了，软件也读不到。
- 本地路径只在当前电脑有效，换电脑后需要重新配置。
- 飞书素材包依赖全局飞书 App ID / Secret；Space ID 用来限制当前项目读取哪些知识库。
